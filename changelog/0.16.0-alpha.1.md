This is the next Windows and Linux Alpha after 0.15.1-alpha.1.

## Stream Manager

- The message you put on stream is shown on a Liquid Chrome plate with an On
  stream chip, in Stream Manager chat, Studio chat and Activity.
- Every member's chat row gets a lighter Liquid Chrome plate, with the member
  colour kept as a thin edge.
- The Followers count goes up the moment a follow arrives, instead of waiting
  for the next refresh.

## Buddy

- Streaming Buddy now talks only in its bubble. Auto is gone, so Buddy never
  posts in your chat as you, and greetings show in the bubble.

## Recording

- A record-only take keeps its audio as AAC while you record, so stopping a
  long take is a quick copy instead of minutes of re-encoding.
- A microphone that loses audio to short overruns on a busy computer keeps
  its place instead of going silent.
- Recording uses less CPU when the compositor runs on the CPU.

## Go Live

- When the performance check finds that even the lightest setting will not
  hold, an untouched stream still steps down instead of going out at 1080p30.

## Security

- Release builds turn off Electron's debug and Node escape hatches and refuse
  test hooks.

## Look

- The Liquid Chrome ground now drifts visibly whenever the window is on
  screen, not only when it has focus.

## Linux

- A stream destination that drops or restarts reconnects on its own while the
  recording keeps going.
- If the screen-share dialog goes away, Videorc stops waiting for it and lets
  you try again.
