This is the next Windows and Linux Alpha after 0.9.132-alpha.1.

## Stream quality, separate from recording

You can now set stream quality on its own, and override it per destination,
while your local recording stays at 4K. YouTube 4K streams are prepared at the
quality the encoder really sends, and true 4K broadcasts use the latency
YouTube supports. If a scheduled YouTube event doesn't match the stream, Videorc
says so before you go live instead of failing on air.

## Saving MP4s you can see

After you stop recording, the MP4 saves in the background, and you can now see
it anywhere in the app. When it's ready you get a button to open it, and if it
fails you can retry it. The original recording is always kept.

## Stream Manager fixes

- The last chat status dot is no longer cut off.
- Emotes sit right next to the words on the highlight card.
- Copy link and Copy work in the Stream Manager's chat.

Windows remains an Alpha. See the [Windows Alpha notes](https://www.videorc.com/windows-alpha)
for supported hardware and current limitations.
