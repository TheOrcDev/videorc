## New

- **YouTube total views in your stream report**: the report for a YouTube stream now includes the total views YouTube counted during the stream, next to the viewer peak and average. These are views, not unique people, and they are never added up across platforms. (#1458)
- **YouTube emotes in Stream Manager**: YouTube's built-in emotes, like the blue smiling face, now show as pictures in chat instead of as `:face-blue-smiling:` text. Unknown or member-only emotes stay readable as text. (#1445)

## Improvements

- **OBS import brings your stream key**: importing an OBS setup for YouTube, Facebook or Kick now also brings the stream key, and it only changes the destination you named. YouTube Vertical is no longer switched on when you import YouTube. (#1495)
- **Imported files read right in the Library**: an imported `.MKV` (any letter case) can be exported to MP4, and an imported `.mov` is labelled MOV instead of MP4. (#1478)
- **Stream report and settings recover on their own**: if the stream report settings fail to load, Videorc says so, retries and offers Try again. The soundboard does the same instead of staying on "Loading sounds…". Chat, privacy and Discord settings keep working after Videorc reconnects. (#1498, #1482, #1489)

## Fixes

- Notes never report a failed save as Saved, and never save blank text over notes that failed to load. (#1483)
- Clean cut: an edit you make while Save is still running stays as an unsaved change instead of being lost. (#1490)
- Library: renaming or deleting a recording keeps every page you had loaded, instead of jumping back to the newest 50. (#1485)
- Library player: when a recording's link expires and refreshes, playback keeps its position and keeps playing. (#1493)
- "Show every" banners no longer appear while only Clips is buffering. They run only while you record or go live. (#1480)
- The scheduled end time of an X broadcast is correct across a daylight saving change. (#1479)
- A While held sound pad started with Space or Enter stops when the key is lost, for example when focus moves away. (#1492)
- Typing a number in a slider and pressing Escape cancels it, and a locked slider can no longer be reset by double-clicking. (#1496)
- Chat: every message that could not be sent puts your words back in the box. (#1497)
- Choosing a missing thumbnail again shows its preview. (#1494)
- Sidekick Community: the People list loads more people as you scroll. (#1484)
- Closing and reopening the preview window no longer logs stray errors. (#1481)
