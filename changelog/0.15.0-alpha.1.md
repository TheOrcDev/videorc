This is the next Windows and Linux Alpha after 0.14.0-alpha.1.

## Setup

- A fresh install opens on a Welcome screen over a Liquid Chrome live
  background, with one card for Screen Recording, System audio, Microphone and
  Camera. Setup then walks through what you are making, your look, a sound
  check and where you stream.
- Run it again from Settings, General, Setup.

## Studio

- Chat in the Studio: turn it on in Settings, General, Chat, and your livestream
  chat shows under Session while you are on air. A click shows a message on
  stream.
- The Preview shows exactly what goes out: every showing banner and the Buddy,
  in place, from the first frame.
- A saved scene keeps its microphone and System audio on or off.
- Liquid Chrome colours reach every window.

## Livestream

- Facebook is a destination in Livestream. Paste the stream key from Live
  Producer.
- An untouched stream on a slow CPU compositor steps down to 720p30 for the
  session instead of dropping frames.

## AI agents

- Settings, Remote, Agents lets Claude Desktop, Claude Code, Cursor, Codex,
  VS Code and other agents control Videorc through its own MCP. It is off by
  default.

## Linux

- A picture background is drawn once instead of every frame, so a still
  background no longer halves the 1080p30 frame rate on a CPU compositor.
- A busy encoder no longer puts the picture a second behind the sound, and the
  file no longer runs longer than the take.

## Fixes

- The first open of the Library renders instead of staying on "Opening
  Videorc" on slower computers.
