## Fixes

- A silent session microphone is reported, never shown as Receiving. (#1139)
- A camera stuck at a low frame rate says so instead of Receiving, and above
  1080p the camera takes the mode with the most canvas-shaped picture. (#1128, #1138)
- Idle screen frames are not counted as drops, and a drop names its stage only
  while drops are recent. (#1121)
- Record and Go Live drop the automatic Clips ring on a software encoder. (#1151)
- A raw stream frame waits out a starved FFmpeg. (#1123)
- An asset import waits behind a starter sound instead of being refused. (#1141)
- Beams, Ghost Fibers and Color Bends draw the same on every GPU. (#1149)
- A page that is still loading names itself; only the first page says
  Opening Videorc…. (#1127)
- A build without update metadata skips update checks and says so once. (#1129)
- Crash records say who ended the backend. (#1132)

## Under the hood

- CI, smoke, lab and test-harness fixes; backend builds are clippy-clean and
  CI lints both. (#1037, #1049, #1118–#1120, #1131, #1133, #1134, #1136, #1137,
  #1142–#1147, #1150, #1152–#1154, #1156)
- Heavy local builds and smokes wait while Videorc is live on the same machine. (#1163)
