## X comments, finally in the same feed

If you stream to X from Videorc, you have probably noticed that X comments
never reached the Comments window. X retired the way apps used to read live
chat, and the feed went silent. X has now given Videorc access to its new
live chat delivery, and this update switches to it.

- **One feed for everything.** X comments land in the same Comments window as
  YouTube and Twitch, in order, with the viewer's name and avatar. X
  subscribers are marked as members.
- **Nothing to reconnect.** It uses the X Live authorization you already gave
  Videorc. You do need to be signed in to your Videorc account, because X
  delivers chat to Videorc's servers first and the app picks it up from there.
- **It heals by itself.** If your network drops for a moment, the X row shows
  "reconnecting" and comes back. It no longer gives up for the rest of the
  stream.
- **Honest status.** When X comments cannot work, the X row tells you why:
  sign in to Videorc, or authorize X Live again.

## Good to know

- X comments work for native X broadcasts started from Videorc. A custom
  stream key to X still has no comments, because X cannot tell whose broadcast
  it is.
- X chat messages pass through Videorc's servers on their way to your app and
  are deleted within 24 hours.
- Sending a message to X chat from Videorc works as before.
