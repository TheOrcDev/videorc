## A clearer Orcle tab

The Orcle tab used to be one long page with the switch, the voice commands,
the last stream report and the settings stacked on top of each other. It is now
organized into tabs, the same way Settings works, so each part of Orcle has its
own place and is easier to find.

## Orcle's eye

Orcle now has an official mark: the Orcle eye. It replaces the simple orc head
wherever Orcle appears in the app.
