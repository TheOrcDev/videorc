This is the next Windows and Linux Alpha after 0.9.124-alpha.1.

## An empty window recovers

Some Windows testers saw the Videorc window turn into a title bar over an
empty window, and it stayed that way until the app was restarted. Videorc now
reloads the window by itself when that happens. If it keeps happening,
Videorc asks whether to reload or quit, and it records why, so a support
report can tell us the cause.

If you saw this on an earlier Alpha, pressing Ctrl+R brings the window back.

## Livestream setup in plain words

Each destination card now asks how you want to connect: **Sign in** or
**Stream key**. A signed-in account is one row with your avatar, name and one
status. The right column is now **Ready to go live**: it names each
destination that is not ready and opens its card when you click it.

## Screen and Camera in one click

Studio Inputs has separate **Screen** and **Camera** rows. Each row is the
list itself: Screen shows your screens and windows under their own headings,
and Camera starts with Off.

## Linux performance check

The performance check could keep recommending 720p from an old result, or
save a result when nothing had been measured. Both are fixed, and software
encoding now uses more than one processor core.

## Smaller fixes

- The sidebar update chip reads "Restart to update" and no longer truncates.
- Settings section headings no longer carry icons.

Windows remains an Alpha. See the [Windows Alpha notes](https://www.videorc.com/windows-alpha)
for supported hardware and current limitations.
