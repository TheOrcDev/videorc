## Improvements

- **Camera and Preview sooner at launch**: Videorc no longer waits on an account check from the web before it starts the camera, and the first Preview starts right away.

## Fixes

- **Scene changes stick**: a scene change, such as a new background, made just as Record, Go Live or the Clips buffer starts is no longer undone by that start.
- **A slow web never restarts Videorc**: when videorc.com is slow to answer, Videorc no longer restarts its engine, and mute, Save clip, markers and scene controls never wait behind it.
