## New

- **Notifications bell**: a bell at the right end of the status bar, in the main window and in Stream Manager, now holds the warnings Videorc used to raise as toasts. It shows an unread count, turns amber while a warning is open and red while something urgent is, and each entry has a way to act on it or clear it. A subject appears once, so a silent microphone is one entry instead of several toasts. Open it with Shift+Command+B (Ctrl+Shift+B), or choose "Open notifications" in Command+K. (#1528, #1533)

## Improvements

- **Lighter startup**: Videorc collects your background pictures once before it connects, the account menu loads when you first reach for it, and the window code is minified, so Videorc opens with less work. (#1508, #1511, #1512)
- **Recording uses less memory churn**: the audio writer reuses its working buffers instead of allocating new ones for every 10 ms chunk. (#1518)
- The Notifications bell fits the status bar at the narrowest window width, 640 px. (#1533)

## Fixes

- Toasts no longer leave a listener behind each time one is shown, so a long session stays light. (#1515)
- Chat, highlight and milestone cards release the avatar and emote images they decoded once each card is drawn. (#1516)
- The avatar and emote image cache is capped at 256 entries instead of growing for the whole session. (#1517)
- Starting X chat again for a destination that is already running replaces its viewer sampler and chat connection instead of stacking another, which could poll twice and deliver the same chat twice. (#1524)
