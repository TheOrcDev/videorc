This is the next Windows and Linux Alpha after the 0.9.117-alpha.1 pilot.
On Windows, Studio is the same as that cut. On Linux, you can finally use
a real microphone and camera, and a second screen preview no longer gets
stuck.

## Linux microphone and camera

Videorc on Linux used to list no microphones and no cameras, even when
the system already had them. It now finds PipeWire and PulseAudio
microphones and V4L2 cameras.

Pick a microphone and you get a live level before you record. The
recording includes that microphone. If Videorc cannot find any input, the
Mic row says so and names PipeWire or PulseAudio, instead of showing an
empty list.

Pick a camera and you get a live preview. A camera-only or camera-in-layout
recording uses the real sensor, not a test pattern. If Linux will not
open the camera, the row stays visible and tells you to add your user to
the `video` group and log in again. A camera already in use by another
app is named as busy.

Changing microphone mid-session is not available on Linux yet. The
session keeps the microphone you started with.

## Linux screen preview

On Linux, opening screen preview a second time in the same run could hang
forever: the first share worked, the next one never came back, and
recording never started. Videorc now keeps the desktop portal connection
alive for the whole run, so you can preview, stop, preview again, and
then record.

Linux Alpha is still early software. Treat this AppImage as a test
artifact, not a supported production install.

Windows remains an Alpha. See the [Windows Alpha notes](https://www.videorc.com/windows-alpha)
for supported hardware and current limitations.
