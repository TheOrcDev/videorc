This is the next Windows and Linux Alpha after 0.12.0-alpha.1.

## Better recordings

- Exported MP4s have exact frame times, so editors see a constant frame rate.
- Every recording carries its creation time, a timecode and marker chapters.
- The Combined file is exported before the separate files, and free space is
  checked before an export or a repair backup.
- A repair keeps every stream, the chapters and faststart.
- Recordings over 20 minutes get a quick sampled check instead of a full
  decode.
- When the machine can't keep up, the separate files are shed first so the
  Combined recording keeps up. The Camera file is the camera's own size.
- A 2-input mic interface no longer distorts the mic, and the peak limiter
  runs on every path.
- Clips keep every frame at the 2-second segment joins, and stale `.partial`
  files are swept.

## Windows

A refused Record start now keeps its reason in the logs, so a support bundle
says why. The automatic Clips start is refused before it opens the
microphone on a PC with a software encoder, instead of reopening it again
and again. Thanks to Pete for the fix.

## Linux

- Record reaches Recording in about 0.4 s instead of about 1.1 s.
- A busy desktop no longer loses the microphone in recordings.
- After a session, the idle preview goes back to its own size instead of
  costing 2 to 5 cores until restart.
- Live backgrounds get a GLES config instead of always showing the poster.

## Fixes

- The Studio gallery no longer marks a scene as selected while the layout is
  Freeform.
- With Screen set to None, the Studio can switch to 9:16 again, and a
  turned-off source now says it is off.
- Banners drag across the Scene canvas again.
- Go Live no longer shows a false "Chat limits" warning for X, since X chat
  reads and sends.
