## Fixes

- X Live uses X's /2/sources and /2/broadcasts routes before the 2027-01-01 cutoff. (#1231)
- Windows Record shows Recording once the first Media Foundation frame reaches FFmpeg. (#1191)
- When one live layout replaces another, the replaced layout reports that it was replaced, not a capture failure of the new one. (#1194)
- Clips handover is smoother: scenes and sources picked around the ring start land in the new scene. (#1232, #1227, #1223)
- Linux recordings and streams survive a 6 s FFmpeg freeze. (#1230)
- A recording that fails while it is running isn't recovered as a normal Stop. (#1224)
- An early Stop releases the audio input at once. (#1222)
- An applied picture background shows as applied on its Assets tile. (#1225)
- Resizing Preview after a failed first request keeps the new size. (#1216)
