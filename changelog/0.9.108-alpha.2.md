This is the first Linux Alpha **candidate** for Videorc 0.9.108. It is meant
for internal validation on Ubuntu 24.04 before any public Linux Alpha
program opens.

## What this build is for

- Confirm that the AppImage starts, captures display and camera through
  PipeWire and the desktop portal, and records with the pinned LGPL FFmpeg
  bundle.
- Exercise VAAPI hardware encoding on machines where the driver stack exposes
  it; otherwise expect a software fallback path.
- Prove packaging, checksums, and updater metadata for the **private**
  candidate prefix — not a promoted public release.

## Not included yet

- No public download on videorc.com and no flip of the Linux Alpha update
  pointers.
- Named-box packaged smoke and promotion to the public `releases/linux-alpha/`
  path remain follow-ups after this candidate is accepted internally.

Linux Alpha is early software. Treat this AppImage as a test artifact, not a
supported production install.
