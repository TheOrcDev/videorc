## X in the Stream Manager

The viewer count in the Stream Manager now includes people watching your
broadcast on X, next to YouTube and Twitch.

X followers now count toward the followers total. Videorc reads them with
the same X authorization that starts your broadcast, so you no longer see
"Reconnect X" while you are live.

## New follows in Activity

Activity now lists new followers as they arrive. X never says who followed,
so X rows read "3 new followers". Twitch does the same until you grant the
follow permission in Livestream → Setup → Reconnect Twitch; after that,
Twitch follows show by name.

## Smaller fixes

- In full screen, the close, minimize and zoom buttons no longer sit on top
  of the Stream Manager title.
- In Settings → Global shortcuts, the horizontal and vertical layout
  shortcuts sit in padded rows that match the shortcuts above them.
