## Better recordings

This release goes through recording from the microphone to the exported
file.

### Exports and files

- Exported MP4s have exact frame times, so editors see a constant frame rate.
- Every recording carries its creation time, a timecode and marker chapters.
- The Combined file is exported before the separate files.
- Free space is checked before an export or a repair backup.
- A repair keeps every stream, the chapters and faststart, and cleans up its
  temporary files and backups.
- Recordings over 20 minutes get a quick sampled check instead of a full
  decode.

### Separate files

- When the machine can't keep up, the separate files are shed first so the
  Combined recording keeps up.
- The Camera file is the camera's own size.

### Sound

- A 2-input mic interface no longer distorts the mic.
- The peak limiter runs on every path.
- A mic that isn't at 48 kHz gets a warning.

### Clips

- Clips keep every frame at the 2-second segment joins.
- A clip is written to disk before it is moved into place, and stale
  `.partial` files are swept.

## Fixes

- The Studio gallery no longer marks a scene as selected while the layout is
  Freeform.
- With Screen set to None, the Studio can switch to 9:16 again, landing on a
  vertical scene your sources can show. A turned-off source now says it is
  off instead of "unavailable".
- Banners drag across the Scene canvas again, and pressing a banner's picture
  grabs the banner.
- Go Live no longer shows a false "Chat limits" warning for X, since X chat
  reads and sends.
- A refused Record start now keeps its reason in the logs, and the automatic
  Clips start is refused before it opens the microphone.
