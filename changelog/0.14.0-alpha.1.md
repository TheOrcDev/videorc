This is the next Windows and Linux Alpha after 0.13.0-alpha.1.

## Discord

Connect up to 10 Discord webhooks in Livestream → Setup → Discord, one per
server. Every public Go Live is announced in each of them, and a slow or
deleted server never delays the others.

## Audio

- The Studio's Microphone section is now Audio: the Microphone and System
  audio sit side by side on one meter scale, each with its level and a Gain
  fader, so you can balance your voice against game or music audio without
  opening Sources.
- The System audio meter moves whenever Clips is keeping audio.

## Scene and Clips

- Dragging a banner, the Buddy or the camera on the Scene canvas shows the
  picture where it will land.
- A refused Record no longer empties the clip buffer, and Record waits for a
  finishing session instead of refusing.

## Windows

Stop no longer fails on NVIDIA graphics cards, and a graphics card that has
run out of encoder sessions frees the ones from stopped takes instead of
refusing the next recording. Thanks to Pete for the fix.

## Linux

- A stalled microphone worker on a busy desktop no longer leaves the rest of
  the session, and the stream, with a silent microphone.
- An AppImage run without its usual launcher variable no longer says it is
  checking for updates forever; Settings → About says plainly that this build
  doesn't update itself.
- The Performance check no longer fails every step when the encoder is slow
  to start.

## Fixes

- The Activity filter row in the Stream Manager has one All chip instead of
  two.
