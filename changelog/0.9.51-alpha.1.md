  - Support bundles shared for troubleshooting now redact sensitive values correctly.

This Alpha is signed with Videorc's own certificate and timestamped, so the
publisher is verified and the signature stays valid over time. SmartScreen may
still show a reputation warning while the new certificate is young — the
Windows Alpha status page explains what to expect and how to verify your
download.

Switching what you capture is also steadier: changing sources mid-session no
longer reports a spurious failure when the switch simply took a moment, and
idle scene switching after a session has been fixed. Support bundles created
for troubleshooting now redact sensitive values properly before you share
them.

Windows is still in Alpha. Livestreaming workflows and broader hardware
coverage remain under validation; report issues through the Windows Alpha bug
template on GitHub.
