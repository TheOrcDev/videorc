## Upcoming streams

The Streaming tab now includes an Upcoming workspace. In a verification build
with YouTube connection enabled, you can prepare an event with a title,
description, thumbnail, time, privacy and audience setting; keep its watch link
after restart; and edit, duplicate or cancel it. Selecting an event prepares its
matching destination. The scheduled time never starts broadcasting by itself:
you choose **Go Live** and later **Stop**.

**Public builds cannot connect a YouTube account yet.** Google approval is
still pending, so the event workflow is available only to authorized verification
builds. The Upcoming workspace reports that limitation. Existing manual RTMP
setup remains the public path for YouTube streaming.
