## Kick

Kick is now one of the destinations in Livestream → Setup. Paste the stream
key from your Kick creator dashboard into the Kick card and it streams
beside YouTube, Twitch and X, within the same five-destination limit.

Connecting a Kick account, Kick chat in the Stream Manager and Kick viewer
counts are built and will switch on in a coming build once Videorc's Kick
app credentials ship.

If you import an OBS profile that streams to Kick, Videorc recognises it and
sets up the Kick destination for you.

## Shortcuts you set by pressing keys

Settings → Global shortcuts no longer asks you to type a combination. Click
a field and press the keys. While you hold modifiers the field shows them
live, and the saved shortcut appears as key chips such as ⇧ ⌘ M.

Esc keeps the previous shortcut. Backspace or Delete clears it. If you press
a bare letter, a system combination such as ⌘Q or ⌘Tab, or a combination
another action already uses, Videorc says so under the row and keeps your
old shortcut. If another app owns a combination, only that row is marked.

The same key chips now appear in the scenes gallery and the shortcuts
reference table.
