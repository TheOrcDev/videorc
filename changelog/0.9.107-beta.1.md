title: Light mode in every window
summary: Turning on light mode now changes the Stream Manager, Notes and Captions windows too, not just the main window.
highlights:
  - The Stream Manager, Notes and Captions follow light mode along with the main window.
  - Switching the theme restyles windows that are already open, with no reopening.
---

Light mode used to stop at the main window: the Stream Manager, Notes and
Captions stayed dark. They now follow the app theme. Turn on light mode from
the sidebar, the command palette or the D key, and every open window switches
with it, glass included.

The detached Preview stays dark in both themes, because it frames your video.
