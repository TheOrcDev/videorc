## Setup

- A fresh install opens on a Welcome screen over a Liquid Chrome live
  background. It asks for Screen Recording, System audio, Microphone and Camera
  from one card, each row with its state and the one action that fixes it.
  Nothing asks for a permission at launch any more.
- Setup then asks what you are making (Recordings, Livestreams or Both), your
  look (orientation, layout, camera shape and a live background), a sound check
  with a level verdict, and where you stream.
- Run it again from Settings, General, Setup, or from the command palette.

## Studio

- Chat in the Studio: turn it on in Settings, General, Chat, and your livestream
  chat shows under Session while you are on air. A click shows a message on
  stream and a click on the live row takes it off.
- The Preview is the source of truth: every showing banner, and the Buddy
  whenever it is on for an output, appears in the Preview where it will appear
  on stream, from the first frame. When something is placed but goes nowhere,
  the Scene page says so.
- A saved scene keeps its microphone and System audio on or off, so choosing it
  brings them back.
- Liquid Chrome colours reach every window: metallic black with its shine, and
  a crisp inverted look in light mode.

## Livestream

- Facebook is a destination in Livestream. Paste the stream key from Live
  Producer, and a Go Live alert reminds you to press Go live there once Videorc
  is sending.
- An untouched stream on a slow CPU compositor steps down to 720p30 for the
  session instead of dropping frames, and the Go Live dialog says why.

## AI agents

- Settings, Remote, Agents lets Claude Desktop, Claude Code, Cursor, Codex,
  VS Code and other agents control Videorc through its own MCP. It is off by
  default, and you can see each connected agent and its last action.
- Streaming Buddy can use the same tools to run the studio for you.

## Fixes

- The first open of the Library renders instead of staying on "Opening
