## New

- **Avatar is under Livestream**: Avatar is used for livestreams, so it now sits in the Livestream group, above Sidekick, instead of Setup. Setup keeps Sources, Scene, Assets, Captions and Output.
- **Library refresh**: the recordings table has clearer status tags, one direct action per row, and a shared menu for the row's actions.

## Improvements

- **Shortcuts follow the sidebar**: Output is now ⌘6, Destinations ⌘7, Avatar ⌘8 and Sidekick stays ⌘9. The View menu, the ⌘K Pages list and the shortcut settings show the new keys.
