## New destinations

- **TikTok**, **Instagram** and **YouTube Vertical** cards join the
  destination list. TikTok and Instagram use a stream key from TikTok LIVE
  Center or Instagram Live Producer; the key changes every broadcast and the
  card links you to the right place each time.
- **Instagram publishes on its side.** Start streaming in Videorc first, then
  press "Go live" in Live Producer once it shows your picture.
- Neither TikTok nor Instagram offers a public chat feed, so the Comments
  window says so instead of pretending.

## Live Co-host

- **Chat rules.** Add plain-language rules such as "no spoilers" or "English
  only" in the co-host settings. They are saved now and the co-host starts
  flagging against them as the new moderation rolls out, without another app
  update.
- **Richer flags.** A flagged message can show what kind of problem it is, who
  it targets and a suggested action. Videorc never bans, deletes or times out
  anyone for you.
- **Suggested comments.** A "Suggested" badge can mark comments worth putting
  on stream. Nothing is shown automatically; you still click to show it.

## Known limitations on Windows

- Streaming both orientations at once from one Go Live is not available on
  Windows in this build: the Windows media path renders one scene, so a
  vertical destination beside a horizontal scene falls back to the standard
  compositor path and has not been verified on physical Windows hardware.
- Unchanged from 0.9.91: this candidate has not yet been verified on physical
  Windows hardware, and Windows DirectShow still lacks the native microphone
  source-loss monitor.
