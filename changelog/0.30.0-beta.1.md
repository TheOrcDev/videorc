## New

- **Drop takeovers into Assets**: drag images from Finder onto the Takeovers section in Assets, or pick several at once in the file picker, up to 32 per batch. Each image shows a placeholder tile while it imports, and if one fails the rest keep going. Thanks to franky47. (#1411, #704)
