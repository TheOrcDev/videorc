This is the next Windows and Linux Alpha. On Linux it follows
0.16.0-alpha.1. Windows skipped 0.16.0, so on Windows it follows
0.15.1-alpha.1 and also brings everything in 0.16.0-alpha.1: Liquid Chrome
highlights in Stream Manager, Streaming Buddy talking only in its bubble, and
faster record-only takes.

## Hide screen

- Press Ctrl+Alt+H, or use the button on Studio's Screen row, the Stream
  Manager or the command menu, to turn your screen into a frosted still on
  the recording, every stream, the Screen file and Clips.

## Recording

- Record refuses a recordings folder it can't write to before it starts,
  instead of failing a moment later.
- When the disk fills during a take, Videorc says so plainly and keeps what
  was recorded. The low-space notice now shows when you press Record.
- A Record start that was refused shows as "Didn't start" in the Library,
  not as an empty MKV.
- Move to Trash keeps the recording's file name in the Trash.

## Studio

- The Chat section appearing on air no longer shrinks the preview card.
- Settings → Shortcuts shows Space in Studio for Record, instead of
  Unassigned.

## Go Live

- The performance check runs with the Clips ring on, so Check this computer
  works and an untouched stream can step down when the computer can't keep
  up.

## Look

- The Liquid Chrome ground is a still again, with no drift.

## Windows

- A slow camera start no longer restarts the backend.
- The Preview window's D3D11 presenter now takes over the Preview window.

## Linux

- An unplugged microphone never falls back to the laptop microphone. Videorc
  keeps recording only from the microphone you chose.
- Folders and sign-in persist on Hyprland, Sway and i3, using the Secret
  Service.
- The AppImage registers itself for videorc:// links.
- The Preview keeps the canvas shape in a tiled window instead of stretching.
- Agents can read the picture from the idle Preview.
