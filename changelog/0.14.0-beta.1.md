## Discord

Connect up to 10 Discord webhooks in Livestream → Setup → Discord, one per
server. Every public Go Live is announced in each of them. A slow or deleted
server never delays the others, and each webhook shows its own status.

## Audio

- The Studio's Microphone section is now Audio: the Microphone and System
  audio sit side by side on one meter scale, each with its level and the same
  Gain fader Sources uses, so you can balance your voice against game or
  music audio without opening Sources.
- The System audio meter moves whenever Clips is keeping audio, not only while
  you record or go live.

## Scene

- Dragging a banner, the Buddy or the camera on the Scene canvas shows the
  picture where it will land, instead of leaving it in place until you let go.

## Clips

- A refused Record no longer empties the clip buffer, so the clip shortcut
  still gives you the last minute.
- Record waits for a session that is still finishing instead of refusing with
  "A capture session is active or finalizing".

## Fixes

- The Activity filter row in the Stream Manager has one All chip instead of
  two.
- The Performance check no longer fails every step when the encoder is slow
  to start.
