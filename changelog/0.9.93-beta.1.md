## Record and Stop feel instant

- **Record starts within a blink.** Videorc no longer rebuilds its preview
  compositor when you click Record: it arms the live preview in place, proves
  the first frame from the frames it is already rendering, and no longer waits
  for the muxer's first progress report before it shows "Recording". On a warm
  Studio the recording is running about a tenth of a second after the click,
  down from roughly a second.
- **Stop is immediate.** The Record button comes back the moment the capture
  file is closed. The MP4 export, captions and thumbnail now run in the
  background: the Library row shows "Saving MP4…" with progress and swaps to
  the finished file by itself. Quitting during a save waits for it to finish,
  and a failed export offers "Retry export".
- **Microphone stays ready.** While Studio is on screen, the selected
  microphone is kept open so recordings start with audio in lockstep with the
  picture. Hiding the window releases it. Settings → "Keep microphone ready
  while Studio is visible" turns this off.
- **Diagnostics show the numbers.** The Diagnostics tab has a new "Record
  latency" group with click → recording and click → idle timings and the
  slowest start phase, so a slow start is explainable instead of a feeling.
