## Windows: reinstall once

Windows versions 0.18 to 0.21 can fail to install an update on a busy machine, and they can't fix that themselves. If you're on one of them, download Videorc from https://www.videorc.com/download and install it once. From 0.22.0 on, updates install by themselves. (#1289)

## New

- **Viewer pictures in the chat box**: each chat row on stream shows the viewer's picture as a small circle beside their name, or their initials when they have none. (#1281)
- **Hide edges** for the green screen: Left, Top, Right and Bottom fields under Spill removal make those edges of the camera see-through, green or not. (#1291)

## Fixes

- The green screen keys out the screen where it falls into shadow, so dark corners no longer show the wall behind it. (#1291)

## Windows

- Updates no longer fail and download again because the signature check ran out of time on a busy machine. (#1289)
- Stop no longer cuts the end off a take when the recording encoder is behind. (#1284)
- A camera keeps its full picture after you switch from Screen + Camera to camera-only. (#1285)
- The floating Preview's picture stays on its window, including on displays scaled above 100%. (#1286)
- Recording and going live start sooner: the Media Foundation encoder gets ready while FFmpeg starts. (#1293)
