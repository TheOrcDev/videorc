# Videorc 0.33.0 release

## Scope and source

0.33.0 is a **MINOR** release from 0.32.1 (record #1540; two feat commits in
the range): Avatar moves from Setup to Livestream above Sidekick with the
sidebar shortcuts renumbered (#1541), and a Library refresh with a cleaner
recordings table (#1544). Both are the owner's PRs, merged before this release.
Unrelated open PRs (#1542, #1543, #1416, #1345) stayed out.

- Version/changelog PR: #1545, squash `1fd74e997c5d412f4cdb3c5a1625b95249946028`. PR checks:   17 pass    2 skipping .

- Windows and Linux exact-candidate owner waivers: #1548, squash `3a3e299cdb2eb604b52d38eb7a4897056e0b4d98`.
  The Windows waiver names `0.32.1-alpha.1` as its predecessor.
- Platform order: **macOS first**, then Linux and Windows. Main held still from the version merge until the waivers merge.
- No unrelated PRs merged during this release.
- Release started **2026-11-19 14:49 CET**; all three platforms live at
