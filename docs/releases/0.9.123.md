## Scope and source

Since macOS 0.9.122 (`88bf2e3137d993f1fe49387bf4a5f99f1935a63b`):

- **#500, live captions on both stream legs (plan 077).** Dual-orientation
  livestreams now burn captions on the horizontal and vertical videos,
  including when captions are turned on mid-stream. Vertical captions are
  sized for a phone screen and sit clear of TikTok / Shorts / Reels UI.
- **#501, toasts stay clear glass.** Success, warning, error and info
  toasts keep the same glass panel; only the 16 px icon changes colour.
- **#496** shipped earlier on the Linux 0.9.122-alpha.1 candidate and is
  not part of this macOS cut.
- #503 (bump).
