# Videorc 0.20.1 release

Status (2026-11-05): macOS `0.20.1-beta.1`, Windows `0.20.1-alpha.1` and
Linux `0.20.1-alpha.1` are all **published**. Windows and Linux are
owner-waived. 0.20.1 is a patch: the stream holds its frame rate on a thin
uplink or a slower Mac (#1186), and a Windows scene with a background stays
on D3D11 from its first frame (#1174).

The owner asked for the whole release end to end. Physical acceptance waived
per OrcDev.
