# Videorc 0.25.2 release

## Scope and source

0.25.2 is a **PATCH** from 0.25.1: the green screen keys the camera before
shrinking it, so a shrunk camera's edges stop crawling and shimmering (#1344,
plan 233). Nothing else merged to main since 0.25.1 (record #1340).

- No fix PR was needed. Main `8d8149d1` passed Linux gates (with Linux
  clippy) and Windows clippy. CI JS failed one test,
  `studio-provider.integration.test.ts` "resumes the cloud show through
  cloud.show.resume with no platform setup" (an unexpected "Couldn't join the
  room" toast). #1344 touches Rust only and its PR JS passed; the test passed
  three times locally, and the failed job passed on rerun, so it is a flake.
- CI "Rust (test + clippy + fmt)" fails its advisory audit on
  RUSTSEC-2026-0523, -0524 (quinn-proto) and -0538 (quinn-udp). This job is on
  the runbook's known-bad list and the release workflows do not run the audit,
  so the release went ahead with the audit **waived**. The fix is contributor
  draft #1343 (Cargo.lock only), not merged here.
- The long Windows stability gates were not waited for (same bar as 0.22.1 to
  0.25.1).
- Version/changelog PR: #1346, squash
  `98e683ad43a9c56c97953312ed43894a486d469f`.
- Frozen artifact source for all platforms:
  `98e683ad43a9c56c97953312ed43894a486d469f`.
- Windows and Linux exact-candidate owner waivers: #1347, squash
  `6f1549a859f044327b3b405b550da2854dcaaf0d`.
- No unrelated PRs merged during this release.
- Release started **2026-11-13 22:22 CET**; all three platforms live at
  **23:25 CET** (about 1 h 3 min).
