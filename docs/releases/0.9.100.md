are verified. Windows `0.9.100-alpha.1` completed its unsigned candidate job, but the protected
signing job was never approved. The run was cancelled when the release owner
requested a new version for both platforms. No signed Windows 0.9.100 candidate

Publication proceeded without waiting for unfinished endurance and
manual/provider acceptance gates. Those checks are not claimed as PASS.
