# Videorc 0.19.0 release

Status (2026-11-04): macOS `0.19.0-beta.1`, Windows `0.19.0-alpha.1` and
Linux `0.19.0-alpha.1` are all **published**. Windows and Linux are
owner-waived. 0.19.0 is a minor: Videorc Camera, your program as a camera in
Meet and Zoom (#1091, #1092), moving and resizing the scene while recording
or live (#1059), chat on stream (#1095), Freeform work (#1098, #1100, #1102),
the Stream Manager on top (#1058) and Edit scene in ⌘K (#1056), plus fixes
#1038–#1116.

The owner asked for the whole release end to end, without pausing for
approvals. Physical acceptance waived per OrcDev.

## macOS 0.19.0-beta.1 (published 01:16 CET)

- Local build from `84566243`. The first attempt stopped in
  `release:preflight:macos`: `VIDEORC_MACOS_PROFILE_APP` (the Videorc Camera
  Developer ID provisioning profile, plan 214) was not in
  `~/.videorc-release.env`. Rebuilt with it pointing at
  `~/.videorc-signing/videorc-app.provisionprofile`; codesign, notarization,
  stapler, Gatekeeper, the camera extension checks and one embedded profile
  (in the app only) passed. Uploaded to every origin.
- `/api/updates/latest-mac.yml` serves `0.19.0`.
