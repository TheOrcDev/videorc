# Videorc 0.15.1 release

Status (2026-10-28): macOS `0.15.1-beta.1`, Windows `0.15.1-alpha.1` and
Linux `0.15.1-alpha.1` are **published** (Windows and Linux owner-waived).
0.15.1 is a patch bump (fixes and polish only): #888, #889, #890, #892, #897,
#898 and, added at the owner's request after the first bump, #900 (the
Liquid Chrome ground drifts slightly in the focused window).

The owner asked for the whole release end to end, without pausing for
approvals or merges. The owner waived physical acceptance per OrcDev.
