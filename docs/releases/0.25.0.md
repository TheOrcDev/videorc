# Videorc 0.25.0 release

## Scope and source

0.25.0 is a **MINOR** from 0.24.0: HTML banners on Windows and Linux, so they
are now on every platform (#1326, plan 232 S11); the stream watchdog and
Community, the free local parts of #727 (plans 223 and 225); and the status
bar's Clip chip is gone (#1332). Videorc Cloud and talk shows from #727 stay
behind their web launch switches and are not announced. Internal only: #1328
and #1320 (Windows smoke tests), #1331 (plan 233 docs).

- Fix PR: #1333, squash `4add70f8af873d66b571825b2dfe20ebab862f87`. Main was
  red after #727 on two tests: a community phrase ("say hello to") was read
  from an unaddressed Buddy ("I told Buddy to say hello to Jay"), now refused
  like greetings; and the sign-in-expired test now awaits its lazily loaded
  toast. CI JS, Linux gates (with Linux clippy) and Windows clippy passed. The
  long Windows stability gates were not waited for (same bar as 0.22.1 to
  0.24.0).
- Version/changelog PR: #1334, squash
  `7bf49b715bc53ade21f521528ce6ea2f71e46bf1`.
- Frozen artifact source for all platforms:
  `7bf49b715bc53ade21f521528ce6ea2f71e46bf1`.
- Windows and Linux exact-candidate owner waivers: #1335, squash
  `33cd49f4b3a2fc48c6b783cbdf78207f5699f691`.
- No unrelated PRs merged during this release.
- Release started **2026-11-13 10:59 CET**; all three platforms live at
