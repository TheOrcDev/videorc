# Videorc 0.9.142 release

Status (2026-10-16): macOS `0.9.142-beta.1`, Windows `0.9.142-alpha.1` and
Linux `0.9.142-alpha.1` are **published** (Windows and Linux owner-waived).
The Hetzner mirror is behind (see Known gaps).

## Known gaps

- **Hetzner mirror behind.** From the release Mac, Hetzner
  (`fsn1.your-objectstorage.com`) dropped about one TLS handshake in three
  ("SSL ... reason(1000)"), and the uploader does not retry on transport
  errors. macOS 0.9.142 is on Neon only; a pending record sits in
  `/private/tmp/videorc-rel142/dist/release-origin-pending/`. Eleven
  `pnpm release:sync:origins -- --pending` attempts failed the same way.
  Clients are unaffected (every route serves Neon); only the soak rollback
  copy is stale at 0.9.141. Replay from a working network, or retire Hetzner
  (Neon has been primary for several releases).
- Alpha changelog entries are not public, and no Alpha Discord post was
  sent, as for every Alpha since `0.9.91-alpha.1`.
- The signed-in download pages were not checked by eye.
- The "Windows startup incident diagnostics" job fails on every PR, as
  before this release.
