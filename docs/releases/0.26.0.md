# Videorc 0.26.0 release

## Scope and source

0.26.0 is a **MINOR** from 0.25.2: a stream report email after every stream
(#1360, plan 237), Buddy becomes Sidekick (#1356, plan 236), a tidy Studio
inspector and sidebar (#1352, #1357, plan 235), a camera-only scene's
background frames the camera (#1353), green screen speck cleanup (#1351), the
Preview back in one click (#1308), Windows system audio turned on
mid-recording (#1349), and a faster Windows Hide screen cover (#1342). Also
on main: the talk show join fix (#1359), the quinn RUSTSEC bump (#1343), tests
and docs (#1350, #1354, #1355, #1358), and plan 234 (#1341), which ships with
its server-side switches off and is deliberately left out of the changelog and
announcement until the owner has tested it.

- No fix PR was needed. Main `206996c1` passed CI JS, Linux gates (with Linux
  clippy) and Windows clippy (#1358 and #1308 had merged at 23:46 before their
  own final-head CI; main's run on that head covered them).
- Version/changelog PR: #1366, squash
  `161fa472f0837b949243d79e17fb24792d8213f8`.
- Frozen artifact source for all platforms:
  `161fa472f0837b949243d79e17fb24792d8213f8`.
- Windows and Linux exact-candidate owner waivers: #1370, squash
  `96477be19bebfeaf08445c8e2a7588afba208659`.
- Platform order: **macOS first** (owner decision 2026-11-14 23:53 CET, so the
  owner can test it first), then Linux and Windows.
- No unrelated PRs merged during this release.
- Release started **2026-11-14 23:50 CET**; all three platforms live at
  **02:00 CET** (about 2 h 10 min).
