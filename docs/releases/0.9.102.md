# Videorc 0.9.102 release

Status: preparing macOS arm64 `0.9.102-beta.1` and Windows 11 x64
`0.9.102-alpha.1` from protected main plus this notes-only update. Neither
artifact has been signed or published.

## Owner decisions (2026-09-23)

- **"Merge and release."** The owner asked to merge #395 and release. macOS
  follows the regular Beta scope of 0.9.93 to 0.9.101: build, sign, notarize,
  staple and run the maintained artifact validation, then publish without the
  real-device, endurance (60/15-minute), clean-machine and strict provider
  gates. Those gates are recorded below as not run; no PASS is claimed for them.
- **Windows follows the 0.9.101 route.** After macOS is live, build and sign the
  `0.9.102-alpha.1` candidate from current protected main. Public promotion
  waits for the release owner to commit
  `docs/acceptance/windows-alpha/0.9.102-alpha.1.json`, either a PASS record
  from a physical acceptance run or an owner waiver (first public Alpha). The
  release agent does not author it.

## Scope and source

Since macOS 0.9.101 (`14d8ffad408b783abeb9ea4b3cb7b55e2531edbc`), protected
main gained:

- **#395, real glass and a native look in every window (plan 050).** Real
  macOS window glass in all five windows, glass badges, the desktop-scale
  layout, the native context menu, and Mica on Windows 11 for the main window.
  Its evidence is in
  [the plan 050 acceptance note](../acceptance/2026-09-23-real-glass.md).
- **#392, the selected tab is marked.** The Streaming tab's Setup and Upcoming
  switch showed no selected state.
- **#393, Windows auto-update for installed Alphas (plan 048).** Windows only;
  macOS behaviour is unchanged.

Windows `0.9.101-alpha.1` never produced signed bytes. Its candidate run
[35850598341](https://github.com/TheOrcDev/videorc/actions/runs/35850598341)
(source `6418c739`) waited for sign approval while protected main advanced to
#393, so it could no longer sign. It is superseded by `0.9.102-alpha.1`, whose
entry replaces the unpublished `0.9.101-alpha.1` changelog entry. Windows
therefore also carries everything in the 0.9.101 Alpha notes.

Mac source commit: pending merge of this notes update. Windows candidate source
commit: recorded after macOS publication. Signed artifact identities, workflow
URLs, the Windows acceptance record and announcement results are pending.
