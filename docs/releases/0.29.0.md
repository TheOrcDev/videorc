# Videorc 0.29.0 release

## Scope and source

0.29.0 is a **MINOR** from 0.28.2 and shipped on **macOS only**. Windows and
Linux were skipped; the owner asked for a new release (2026-11-16 11:54 CET)
and 0.29.1 carries all three platforms from one commit.

- Version/changelog PR: #1410, squash `e5212b1b05c928104b83d1164e47c5815dbb9ea3`.
- Artifact source: `e5212b1b05c928104b83d1164e47c5815dbb9ea3`.
- Windows owner waiver: #1412, squash `089e332b83bd6d97e9d4d1c3458929981fa64f6d`
  (not used for a public promotion).
- No Discord announcement for 0.29.0; the 0.29.1 announcement covers it.

## Windows 0.29.0-alpha.1: skipped

The public feed still serves 0.28.1.

- Candidate https://github.com/TheOrcDev/videorc/actions/runs/43833033748
  passed (installer SHA-256 `a4f0e017…f994f`).
- Pilot promote https://github.com/TheOrcDev/videorc/actions/runs/43850330253
  uploaded and verified the R2 objects and the R2 pilot pointer, then failed
  on the Hetzner mirror: the readback of the ~215 MB installer exceeded the flat

  owner switched to 0.29.1. The private pilot channel may point at
  0.29.0-alpha.1 until the 0.29.1 pilot advances it. Fix: #1414.
