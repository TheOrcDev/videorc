# Videorc 0.9.143 release

Status (2026-10-16): macOS `0.9.143-beta.1`, Windows `0.9.143-alpha.1` and
Linux `0.9.143-alpha.1` are **published** (Windows and Linux owner-waived).

## Source

- Bump and changelog: #721, squash `a2eaae94f2723a39e8f86c03128bd7f186cd2888`.
  macOS and Linux build from this commit. The scope since 0.9.142 is #717
  (the "Let <Buddy> post as you?" prompt shows the Buddy it names), which
  macOS and Linux 0.9.142 shipped without, and #718 (a test-only change).
- Windows 0.9.142 was already built after #717, so for Windows this is a
  version-parity release. It keeps all three platforms on one version.
- Windows builds from `d68c18d145ebfb8b7f7c778e73b1e85fa10bc70f` (the Linux
  waiver, #722, on top of the bump; docs only). The first candidate run,
  38943428059 from `a2eaae94`, failed twice, before signing, on runner timing
  checks that pass on the same code elsewhere:
  - `ffmpeg_terminal_interrupt_is_session_ended_not_unknown_audio_state`
    (a 5000 ms pipe EOF wait);
  - then the preview smoke, whose recording lasted 28.43 s against
    16.49 s ± 1.5 s;
  - nothing was signed or stored, and the code is identical to Windows
    0.9.142, which passed both checks.
- Owner waivers: Linux #722 `d68c18d145ebfb8b7f7c778e73b1e85fa10bc70f`;
  Windows #723 `20cee1ecb406d8b45ec45f24a103a01f09b5d3e4`. The owner gave
  standing permission in-session:
  "you just approve it and waive, you have my permission".

## macOS 0.9.143-beta.1 (published)

- Built locally in `/private/tmp/videorc-rel143` with `RUSTUP_TOOLCHAIN=1.98.0`.
  The network dropped while Apple notarized the DMG (the app was already
  notarized), so `staple-dmg.mjs` was rerun alone: it re-signed, notarized
  (about 70 minutes in Apple's queue) and stapled the DMG. Then
  `release:manifest:macos` and `release:validate:macos` passed.
- DMG SHA-256
  `75a732797e2594bff9789fb645e11a0075e2a9d7cbe47f963a7292449c1c6cd0`,
  186,731,865 bytes.
- Uploaded to Hetzner and Neon. Hetzner took every object this time, so the
  mirror is current again; it still lacks the 0.9.142 objects, which no
  pointer references. The upload withheld `0.9.143-alpha.1`.
- `/api/updates/latest-mac.yml` and the mirror route serve `0.9.143`; the zip
  and blockmap resolve to Neon; `/releases/0.9.143-beta.1` and `/changelog`
  show the entry. Discord sent.
