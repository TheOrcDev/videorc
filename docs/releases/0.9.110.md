## Scope and source

Since macOS 0.9.109 (`e38809a857039295c6b7354ed59c9010c07dda72`):

- **#432, smaller live-canvas selection chrome.** The renderer sized the
  chrome against the session output width, but the native-preview run
  composes into the surface's device-pixel bounds, so handles came out
  ~1.9x too big. The chrome now carries the slot's on-screen width, the
  backend derives the scale from the frame it draws into, handles are 6 px
  and lines 1 px (measured on screen at two window widths).
- #429: a Linux-only `0.9.108-alpha.2` changelog entry (withheld by the
  macOS uploader; not part of this release).
