## Scope and source

Since macOS 0.9.108 (`fdc50b4d691d6781ceb54855ff36ad26d0b580e8`), protected
main gained:

- **#420, the Scene canvas shows the real picture (plan 058).** The docked
  native preview glues into the Scene canvas; drags send per-frame editor

  selection chrome as blended quads; release keeps one authoritative commit;

  about (plan 060).** Requires videorc-web #42 (merged 2026-09-25 07:36Z,
  spotlight kill switch on until the owner's acceptance stream).

- **Linux plans 0001 to 0009** (#419, #422, #423, #425, #426, #427): Linux
  Alpha groundwork, no macOS user-facing change; #4a0ed677 never rewinds a
  live surface's `frames_rendered` from the compositor pump.
