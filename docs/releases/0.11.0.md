# Videorc 0.11.0 release

Status (2026-10-25): macOS `0.11.0-beta.1`, Windows `0.11.0-alpha.1` and
Linux `0.11.0-alpha.1` are **published** (Windows and Linux owner-waived).
0.11.0 is a minor bump: five more live backgrounds and Retro LCD, an optional
Studio look for LCD screens (#816).

The owner asked for the whole release end to end, without pausing for
approvals or merges. The owner waived physical acceptance per OrcDev.
