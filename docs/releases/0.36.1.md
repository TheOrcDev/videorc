# Videorc 0.36.1 release

## Scope and source

0.36.1 is a **PATCH** release from 0.36.0 (record #1618): fixes,
performance and docs only. Camera and Preview start sooner after launch
(#1615), Record and Go Live starts skip the FFmpeg device listing and refuse
a dead camera at once (#1619), the compositor Preview composes less (#1625),
a slow web answer never restarts the backend (#1621), and a scene change is
never undone by a Clips, Record or Go Live start (#1640, #1643). Also in the
range: #1614, #1620, #1642, #1644, #1645, #1647. Open PRs (#1605, #1610,
#1612, #1616, #1622, #1626, #1627, #1630, #1632-#1637, #1646, #1648, #1649,
#1651) stayed out.

- Version/changelog PR: #1652, squash `c4fef2c48653a6a753999896a7287bd45607ab27`. PR checks:   17 pass    2 skipping .
- Frozen artifact source for all three platforms: `c4fef2c48653a6a753999896a7287bd45607ab27`.
- Windows and Linux exact-candidate owner waivers: #1653, squash `7882999ff818e552e8c1ce315df33737127275a6`.
  The Windows waiver names `0.36.0-alpha.1` as its predecessor.
- Platform order: macOS was meant to go first; Linux went public at 01:37 CET, before macOS (01:47 CET), because a release-script hold matched its own log text. Windows waited for macOS. Main held still from the version merge until the waivers merge.
- No unrelated PRs merged during this release.
- Release started **2026-11-22 00:44 CET**; all three platforms live at
  **01:52 CET**.
