# Videorc 0.32.0 release

## Scope and source

0.32.0 is a **MINOR** release from 0.31.1 (record #1513): the notification
center (plan 250) behind a bell in the status bar (#1528, #1533), startup and
memory performance work (#1508, #1511, #1512, #1518, #1526), leak fixes (#1515,
#1516, #1517, #1524) and parity test hardening (#1519, #1520, #1521). Further
changes in the range (#1510, #1514, #1522, #1523) touch surfaces that stay
**unannounced** (switches stay off) and are not described in the public
changelog or the Discord post.

- Version/changelog PR: #1534, squash `b8d24266418579b9b2ab27590bb4d1ed429a8430`. PR checks:   17 pass    2 skipping .
- Frozen artifact source for all three platforms: `b8d24266418579b9b2ab27590bb4d1ed429a8430`.
- Windows and Linux exact-candidate owner waivers: #1536, squash `e9e3a39e36ce389910a64671536455db2415638c`.
  The Windows waiver names `0.31.1-alpha.1` as its predecessor.
- Platform order: **macOS first**, then Linux and Windows. Main moved during the build; see the release state notes.
- The release merged no unrelated PRs. The owner's own PR #1535 (`7fbdb7ca6`) landed on main at 10:30 CET after the Windows candidate was built; it is not in the 0.32.0 artifacts.
- Release started **2026-11-19 09:21 CET**; all three platforms live at
  **10:53 CET**.
