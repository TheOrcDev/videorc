# Videorc 0.9.128 release (and 0.9.127)

Status (2026-10-03): macOS `0.9.128-beta.1`, Windows `0.9.128-alpha.1` and
Linux `0.9.128-alpha.1` are **published** (Windows/Linux owner-waived).
macOS `0.9.127-beta.1` was published earlier the same evening; its Windows and
Linux Alphas were abandoned before publication.

## Scope since 0.9.126

macOS 0.9.127: `#535` YouTube quota fix (pause and resume, no start
blocking, no toast storms, remote service flags), `#534` highlight card
avatars and emotes, Activity On stream, X Host, Go Live reads Streaming with a
ticking clock, `#532` Studio Microphone section, `#531` Ghostex glass.
macOS 0.9.128: `#533` Sources audio mixer; `#530` shared encode when a second
encoder is unavailable. Windows and Linux 0.9.128 receive all of the above plus
`#530`'s Windows Go Live fixes (shared-encode fallback, opt-in Quick Sync, the
540p performance rung).
