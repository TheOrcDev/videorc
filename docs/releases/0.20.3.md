# Videorc 0.20.3 release

## Scope and source

0.20.3 is a **PATCH** from 0.20.2: fixes to Clips handover, Windows
Recording readiness, live-layout supersession, early Stop cleanup, Preview,
and Linux recording/stream freeze recovery, plus migration of the existing
X Live integration to `/2/sources` and `/2/broadcasts` before 2027-01-01.
No new capability or destination is introduced. Stream Deck #1221 remains
open and is not included.

- Main remained frozen during candidate signing; both waivers merged before
