# Videorc 0.19.1 release

Status (2026-11-05): macOS `0.19.1-beta.1`, Windows `0.19.1-alpha.1` and
Linux `0.19.1-alpha.1` are all **published**. Windows and Linux are
owner-waived. 0.19.1 is a patch: honest source health (silent mic, camera low
fps, idle screen frames), Clips off on software encoders, and Windows/Linux
fixes (#1037, #1049, #1118–#1172).

## Source

- Version and changelog: #1158 (`ecfd30c5`), then #1164 (`5f82d834`) so the
  changelog covers latest main (#1163). #1164 also lists
  `scripts/wait-until-not-live.mjs` as a D3 gate dependency, which fixed the
  JS tests on main after #1163. All platforms build from `5f82d834`.
- Linux owner waiver: #1167, squash `b5be7769f1146e4881cef710001a1bdc1e32a4a4`.
- Windows owner waiver: #1176, squash `87b63b97f6544a28ad384a063f220ff517b497bf`.
  Windows ships from `d50eeb4e9fd605d952885c397f797e1d095ad60a` (later than the
  macOS/Linux tip after silent-mic and related gates landed).
