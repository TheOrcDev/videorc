# Videorc 0.15.0 release

Status (2026-10-28): macOS `0.15.0-beta.1`, Windows `0.15.0-alpha.1` and
Linux `0.15.0-alpha.1` are **published** (Windows and Linux owner-waived).
0.15.0 is a minor bump: a first-run setup on Liquid Chrome (#872, #879, #883),
Chat in the Studio (#873), Facebook as a Livestream destination (#877), the
Videorc MCP so agents and Streaming Buddy can run the studio (#887), and the
Preview source of truth (#880). #885, #886 and #891 were merged first at the
owner's request. #888, #889, #890, #892, #874, #878, #881, #882, #884, #862
and #843 were not in this release.

The owner asked for the whole release end to end, without pausing for
approvals or merges. The owner waived physical acceptance per OrcDev.
