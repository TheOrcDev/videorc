# Videorc 0.22.0 release

## Scope and source

0.22.0 is a **MINOR** from 0.21.0: viewer pictures in the chat box, green
screen shadow keying with Hide edges, and Windows updates that no longer fail
the signature check on a busy machine (Windows 0.18 to 0.21 users reinstall
once), plus Windows recording, camera, Preview and start-up fixes.

- Linux clippy fix after #1293: #1295, squash
  `1edd0523f18211fa01e179990374d15cc5c21d3b`.
- Version/changelog PR: #1294, squash
  `46712d2c76c9dbcea9006e114f98fbebaaac2194`.
- Frozen artifact source for all platforms:
  `46712d2c76c9dbcea9006e114f98fbebaaac2194`.
- Windows and Linux exact-candidate owner waivers: #1296, squash
  `269b4c82fcfa68301f1c32c38c74544d4c84bd7f`.
- Main remained frozen during candidate signing; the waivers merged before
  pilot, and no unrelated PRs merged during this release.
- Release started **2026-11-11 20:22 CET**; all three platforms live at
  **22:23 CET** (about 2 h 1 min, ~1 h of it a GitHub Actions outage).
