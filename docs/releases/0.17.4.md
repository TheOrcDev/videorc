# Videorc 0.17.4 release

Status (2026-11-01): macOS `0.17.4-beta.1`, Windows `0.17.4-alpha.1` and
Linux `0.17.4-alpha.1` are all **published**. Windows and Linux are
owner-waived. 0.17.4 is a patch: since 0.17.3 main has only fixes and polish:
#972, #974, #976, #979, #980, #983, #986, #988 (Record is one metallic red
RecordButton) and #633 (docs). No new integration, destination, platform or
Streaming Buddy capability.

The owner asked for the whole release end to end, without pausing for
approvals. Physical acceptance waived per OrcDev.

## Source

- Bump and changelog: #989, squash `a4e175d80dd504b4753528a9691fead6758b13f1`.
  All three platforms build from this commit.
- Windows and Linux owner waivers: #994, squash
  `e04afcc7af2b67dc02f803fe01151b218e36663a`, merged only after the Windows
  signing job had finished. Nothing else merged to main during the release
  (test-loop PRs #990–#993 were left open).
