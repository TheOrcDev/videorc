# Videorc 0.23.0 release

## Scope and source

0.23.0 is a **MINOR** from 0.22.1: the Stream Manager Screen key for the
Stream Deck moves the Stream Manager between the Presenting and Monitor
screens with a tap or a hold, and says Not on Wayland there (#1307, franky47's
#1306 with review fixes, plan 230). Also a Windows scene switch with Clips on
is confirmed instead of "Couldn't confirm the scene change" (#1288), a Scene
canvas without the live picture says where the picture is (#1301, #1274), and
a Windows record-latency smoke test (#1303, test only).

- Renderer asset budget fix after #1307 and #1301 (main measured 478,060
  gzip bytes against 478,000): #1310, squash
  `c0954af7c4685b1b70095fc0ea4db46f60673683`.
- Version/changelog PR: #1309, squash
  `bf6e9077d17935c51bfb48f85c3fd0e1da3c0388`.
- Frozen artifact source for all platforms:
  `bf6e9077d17935c51bfb48f85c3fd0e1da3c0388`.
- Windows and Linux exact-candidate owner waivers: #1313, squash
  `4eec3d78d82051846d0c9058edf3cb95cc338f9d`.
- Main `196e8a19` before the release: CI Rust, Linux and Windows clippy
  passed; the JS renderer budget failed (fixed by #1310). The heavy Windows
  stability gates on `196e8a19` were still running after an hour and were
  superseded by #1310.
- No unrelated PRs merged during this release.
- Release started **2026-11-12 16:35 CET**; all three platforms live at
  **18:36 CET** (about 2 h 1 min). The macOS build waited about 20 minutes
  for a live Videorc session on the build Mac to end (`wait-until-not-live`).
