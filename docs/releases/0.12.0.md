# Videorc 0.12.0 release

Status (2026-10-26): macOS `0.12.0-beta.1`, Windows `0.12.0-alpha.1` and
Linux `0.12.0-alpha.1` are **published** (Windows and Linux owner-waived).
0.12.0 is a minor bump: a 1-minute clip beside the 30-second clip (#830). The
other changes since 0.11.0 are fixes (#814 Windows raw-pipe fallback from
Pete, #817 to #819, #823 to #829).

The owner asked for the whole release end to end, without pausing for
approvals or merges. The owner waived physical acceptance per OrcDev.
