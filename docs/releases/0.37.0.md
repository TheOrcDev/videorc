# Videorc 0.37.0 release

## Scope and source

0.37.0 is a **MINOR** release from 0.36.1 (record #1654): 57 commits,
with new features. Camera background blur and pictures on macOS (plan 258:
#1660 per-camera Background setting, #1666 the macOS camera effect pipeline,
#1673 the Background control in the Studio, Scene page, ⌘K and Retro LCD,
#1657 system camera effect detection, #1656, #1689). Linux (plan 257):
native V4L2 camera modes and hotplug (#1650), Secret Service, device group and
portal preflight (#1678), a Preview that shows every camera frame (#1690),
VAAPI by default (#1695), the mic surviving a below-realtime encode (#1659),
true stream bitrate (#1649). Windows: 1440p and 4K30 Record on D3D11 (#1610),
#1612, #1637, #1626, #1622. Fixes: hide screen (#1676, #1679, #1696),
notifications (#1668, #1672), alerts (#1675), Clips (#1683, #1687), scenes
(#1697), watchdog (#1665), #1639, #1670, deps (#1663, RUSTSEC-2026-0592),
plus tests, docs and smaller fixes (#1636, #1667 and others). Open PRs
(#1606, #1624, #1661, #1674, #1686, #1693, #1698, #1699) stayed out.
