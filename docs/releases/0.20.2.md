# Videorc 0.20.2 release

Status (2026-11-06): macOS `0.20.2-beta.1`, Windows `0.20.2-alpha.1` and
Linux `0.20.2-alpha.1` are all **published**. Windows and Linux are
owner-waived. 0.20.2 is a patch: a hidden window pauses instead of going
missing (#1211), a custom Buddy shows in the sidebar (#1213), the Clips
ring shares the file encode (#1212), plus recording/folder, FFmpeg startup,
Wayland shortcuts, and Linux OpenH264 fixes after 0.20.1.

The owner asked for the whole release end to end. Physical acceptance waived
per OrcDev.
