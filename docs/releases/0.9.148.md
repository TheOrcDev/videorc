# Videorc 0.9.148 release

Status (2026-10-24): macOS `0.9.148-beta.1`, Windows `0.9.148-alpha.1` and
Linux `0.9.148-alpha.1` are **published** (Windows and Linux owner-waived).

The owner said in-session: "you have my permission to auto approve and auto
waive everything".

## Source

- Bump and changelog: #756, squash `63f9bb6ea47a33df720e401dba643a3ec780ef38`.
  macOS and Linux build from this commit.
- Linux owner waiver: #757, squash `0db1e5bc2db5834f08dcfb472fd8ff589375b0ca`.

  https://github.com/TheOrcDev/videorc/actions/runs/40039872160 from

  upload retry transient 5xx and network failures, HEAD-checking before each

  `9d9151665fc9253b15c91ca350dd75de37587a0f`.

## Known gaps

- No macOS clean-machine or device acceptance pass was recorded, as for the
  recent Betas.
- No physical Windows or Linux acceptance; both Alphas are owner-waived.
- The `CI` workflow on `main` was failing on the release-window pushes and
  was not investigated as part of this release.
- Alpha changelog entries are not public and no Alpha Discord post was sent,
  as for every Alpha since `0.9.91-alpha.1`.
- The signed-in download pages were not checked by eye.
