# Videorc 0.30.1 release

## Scope and source

0.30.1 is a **PATCH** from 0.30.0 (record #1422). User-facing changes: camera
key controls simplified to Off, Green screen and Blue screen (#1426); no more
repeated microphone re-anchors during output stalls (#1431); background repair
work runs at lower priority and defers under load (#1429). #1419, #1421, #1424,
#1425, #1427, #1428, #1430, #1432 and the plan 247 docs (#1423) ship
unannounced.

- Version/changelog PR: #1433, squash `8e2ff863ec48f8fd243b234826089d6a3a1c75e8`. PR checks: 1 pass (CodeRabbit only; see gate notes).
- Frozen artifact source for all three platforms: `8e2ff863ec48f8fd243b234826089d6a3a1c75e8`.
- Windows and Linux exact-candidate owner waivers: #1435, squash `a2e225a9b5f2b047da6c1a471bd0b371b564e5c0`.
  The Windows waiver names `0.30.0-alpha.1` as its predecessor.
- Platform order: **macOS first**, then Linux and Windows. Main held still from the version merge until the waivers merge.
- No unrelated PRs merged during this release.
- Release started **2026-11-16 16:28 CET**; all three platforms live at
  **17:57 CET**.
