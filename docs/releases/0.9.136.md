# Videorc 0.9.136 release

Status (2026-10-06): macOS `0.9.136-beta.1`, Windows `0.9.136-alpha.1` and
Linux `0.9.136-alpha.1` are **published** (Windows and Linux owner-waived).

## Source

- Bump and changelog: #629, squash `edae0c619f1a12ae932cac6ba8a7def85123101b`.
  All three platforms build from this commit.
- Owner waivers: #630, squash `1f0fbbc35768b7f54eb60179dfff4b1424bc6454`. The
  owner said "auto-approve and auto-waive everything" in-session; the records
  were written at 2026-10-06T13:54:32Z after both candidates were built.

## Superseded 0.9.135

- macOS `0.9.135-beta.1` (#627, `ea55c164`) was already public and stays
  public; 0.9.136 is its successor.
- Windows and Linux `0.9.135-alpha.1` were abandoned unpublished: they were
  built before #628. The Windows candidate run 37461705178 was cancelled during
  its unsigned build; the Linux candidate (run 37461709220) was stored privately
  and never published. #629 removed the `0.9.135-alpha.1` changelog entry and
  carried its notes into `0.9.136-alpha.1`.
