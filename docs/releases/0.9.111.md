## Scope and source

Since macOS 0.9.110 (`ab0054661f0b51f24ccae4d865f8e7ccc96c80d3`):

- **#438, Stream Manager on X.** The X viewer poll now asks for
  `broadcast.fields=total_watching,state` (X returned only default fields);
  X followers are read with the "Authorize X Live" OAuth 1.0a token first;
  the audience snapshot records follower gains that Activity lists for X and
  for Twitch without the follow scope; the traffic-light gutter stays in
  fullscreen.
- **#440, Settings.** Layout shortcut rows sit in padded inset groups.
- #435, #436, #439, #442: Linux Alpha work (withheld from macOS publication).
