# Videorc 0.9.93 Beta 1 (macOS)

Record and Stop are instant. The whole instant-record plan (Obsidian:
"2026-09-16 - Videorc Instant Record Start Stop Plan") ships in this beta:
Record starts in about a tenth of a second on a warm Studio, Stop hands the
Record button back immediately, the MP4 is finalized in the background, and the
selected microphone stays ready while Studio is visible.

## Scope

- #341 P0: `smoke:record-latency` (renderer-path Record/Stop cycles through
  remote-control intents), backend start/stop timelines in diagnostics,
  Diagnostics tab "Record latency" group, bounded CoreAudio open, baseline
  note `docs/acceptance/2026-09-16-record-latency-baseline.md`.
- #342 P1: device-probe cache, async idle-preview stop, background export
  permit so Record is never blocked by the previous take's export, renderer
  start-path hop removed.
- #343 P2: instant Stop — terminal `idle` as soon as the MKV closes;
  `RecordingFinalizationRegistry` runs MKV→MP4 export, captions, probe and
  poster in the background (`recording.finalization` events,
  `sessions.finalization_state`); Library "Saving MP4…" row, "Retry export";
  quit and updater gates wait for the job.
- #344 P3 + P4a: history-aware camera cadence and startup barrier, microphone
  leading-silence padding, `Recording` at the first fed frame, FFmpeg output
  proof as a post-`Recording` watchdog.
- #345 P4.1: the live preview compositor is armed in place for a take (capture
  lease, hot-swapped loop config, Metal sampler swap) instead of rebuilt.
- #346 P4.2: one-frame startup barrier when the armed run's history already
  proves live sources.
- #347 P5: warm microphone (`audio.mic.arm/disarm`, warm handoff at
  `session.start`, Settings toggle default on, "Mic ready for instant Record").
- #348 P6: calibration note `docs/acceptance/2026-09-16-record-latency-calibration.md`,
  budgets enforced by `pnpm smoke:record-latency:gate` (recording-studio
  gates + `smoke:local-gates`).
- #349: release-build fix (a test seam had pushed `#[cfg(debug_assertions)]`
  off the caption-contract test source; only the release profile compiled the
  debug-only body).
- #350: version bump to 0.9.93 + changelog entry.

| Record click → recording, cold max |                       970 ms |                         141 ms |
| Stop click → idle, p95             |                       492 ms |                         126 ms |
| MP4 available                      | inline, inside the Stop wait | ~270 ms after idle, background |
