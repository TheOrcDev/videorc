# Videorc 0.9.150 release

Status (2026-10-24): macOS `0.9.150-beta.1`, Windows `0.9.150-alpha.1` and
Linux `0.9.150-alpha.1` are **published** (Windows and Linux owner-waived).
0.9.150 is a hotfix over 0.9.149, which shipped on macOS only.

The owner said in-session: "let's make now a new release of all three
platforms, you have my permission to auto approve and auto waive everything",
then "Let's release again now for all three platforms. We have a hotfix. We
need to push this one as soon as possible."

## Known gaps

- No macOS clean-machine or device acceptance pass was recorded, as for the
  recent Betas.
- No physical Windows or Linux acceptance; both Alphas are owner-waived. The
  downloaded installer's Authenticode signature was checked in CI only, not
  re-checked locally.
- Live backgrounds have never been seen running on a real Windows or Linux
  machine. CI rendered their goldens on WARP and Mesa only.
- The live-background smoke and the A/B performance check ran on a busy host
  (load 14 to 45); a quiet-host rerun is owed (plan 190).
- Installs on 0.9.149 or earlier still have the broken Restart to update
  button while Clips is on. The macOS changelog tells them to quit, wait a few
  seconds and reopen.
- Alpha changelog entries are not public and no Alpha Discord post was sent,
  as for every Alpha since `0.9.91-alpha.1`.
- `/api/updates/mirror/` redirects to the same Neon host as `/api/updates/`,
  so the Hetzner copy was uploaded but not served through the mirror route.
- The signed-in download pages were not checked by eye.
