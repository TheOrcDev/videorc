# Videorc 0.31.0 release

## Scope and source

0.31.0 is a **MINOR** from 0.30.1 (record #1436), 132 commits on main. The
announced user-facing changes: YouTube total views in the stream report (#1458),
YouTube built-in emotes in Stream Manager (#1445), the OBS import stream key and
named-destination fix (#1495), and the QA fix batch #1478-#1485 and
#1489-#1498 (Library import formats and pages, Notes save safety, Clean cut
pending-save edits, player re-grant, banner timing, X broadcast end time across
DST, soundboard and stream report load recovery, settings after reconnect,
sound pad key release, slider Escape and lock, chat draft restore, thumbnail
preview, Community People scrolling, preview lifecycle). The bulk of the
release is Plan 249 (S1-S26: #1438-#1472, #1473-#1477, #1486-#1488, #1499,
#1500) plus the opt-in Program preview as Videorc Camera; all of it ships
**unannounced** (switches stay off) and is not in the public changelog or the
Discord post.

- Version/changelog PR: #1501, squash `bfbecd84f69883896befcce7f3d5addf3a529cc3`. PR checks:   17 pass    2 skipping .
- Frozen artifact source for all three platforms: `bfbecd84f69883896befcce7f3d5addf3a529cc3`.
- Windows and Linux exact-candidate owner waivers: #1502, squash `6284dce790330582514da9dc945d465e024bc9f9`.
