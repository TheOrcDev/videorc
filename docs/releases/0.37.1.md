# Videorc 0.37.1 release

## Scope and source

0.37.1 is a **PATCH** release from 0.37.0 (record #1703): 13 commits,
fixes and polish only. #1693 no yellow border in Windows recordings and
streams (faint streamer-only outline), #1706 vertical Screen + camera and
Side by side show their screen again (one-time repair), #1700 window swap
never hands the next window's frame to the scene on air, #1674 a scene switch
whose connection closed says nothing, #1661 Windows diagnostics sample memory
and FFmpeg without `ps`, #1704/#1705/#1708 Background row and Orc art, plus
tests, docs and ui sync (#1698, #1699, #1686, #1624, #1707). Open drafts
(#1606, #1709) stayed out.

  The Windows waiver names `0.37.0-alpha.1` as its predecessor.
- Platform order: macOS 19:24 CET, Linux 19:53 CET, Windows 20:00 CET. macOS was verified public before Linux or Windows went public (marker-file gate). Main held still from the version merge until the waivers merge.
