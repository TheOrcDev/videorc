# Videorc 0.20.0 release

Status (2026-11-05): macOS `0.20.0-beta.1`, Windows `0.20.0-alpha.1` and
Linux `0.20.0-alpha.1` are all **published**. Windows and Linux are
owner-waived. 0.20.0 is a minor: microphone **Noise reduction** (RNNoise)
(#1036), plus post-0.19.1 fixes (#1051 Quick Sync probe, #1125 caption
FFmpeg paths, #1170/#1172/#1169/#1161 CI/smoke, #1173, #1162) and release
paperwork already on main.

The owner asked for the whole release end to end, without pausing for
approvals. Physical acceptance waived per OrcDev.

## macOS 0.20.0-beta.1 (published 12:54 CET)

- Local build from `091a1f0d` on the Mac release worktree. First attempt
  failed on missing `rust-objcopy`; fixed with `llvm-tools-preview` and a
  `~/bin/rust-objcopy` shim. Codesign, notarization, stapler, Gatekeeper,
  Camera extension checks and artifact validation passed. Uploaded to every
  origin (neon, hetzner).
