# Videorc 0.28.0 release

## Scope and source

0.28.0 is a **MINOR** from 0.27.0: Go Live in polished copper (#1386,
plan 240), avatar creator cancellation races (#1380), Preview startup warnings
when retrying (#1381), and the macOS Metal frame leak (#1374, @franky47).
Sidekick's old wake aliases are retired (#1384, #1385); tests also await lazy
avatar onboarding (#1383). The stale room join fix (#1382) ships behind the
existing server-side switches and is left out of the changelog and announcement.

- Main `7f0e4eca` passed CI JS, Linux gates (with tests and clippy) and Windows
  clippy before the version PR. #1382's earlier failing Linux/Windows/Rust
  checks used the pre-#1385 wake-word test; the final main includes its fix.
- No fix PR or gate threshold changes were needed.
- Version/changelog PR: #1387, squash `92503f80ff96e14c1ca174a653d2d8c58fc99865`.
- Frozen artifact source for all platforms: `92503f80ff96e14c1ca174a653d2d8c58fc99865`.
- Windows and Linux exact-candidate owner waivers: #1388, squash `6a2a2e34a7ccb7a2fa58a44e9b4448cb3f4143c2`.
- Platform order: **macOS first** (owner rule, so the owner can test it), then
  Linux and Windows.
- No unrelated PRs merged during this release.
- Release started **2026-11-15 18:24 CET**; all three platforms live at
  **19:30 CET**.
