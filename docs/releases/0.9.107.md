## Scope and source

Since macOS 0.9.106 (`eea90897782c65763fec3f4d1bc5bb3a6947ce87`), protected
main gained:

- **#411**, the 0.9.106 changelog rewritten as a week ship note (docs only).
- **#412, light mode in every window.** Stream Manager, Notes and Captions
  were dark-always (plan 050): hard-coded `class="dark"` pages and a
  per-window `darkAqua` pin. They now follow the app theme through
  `window-theme-bootstrap.js` (prefers-color-scheme, driven by
  `nativeTheme.themeSource`), so text tokens and the vibrancy material agree
  and a toggle restyles open windows live. Only the Preview stays pinned
  dark. On Windows 11 the three windows get Mica like main (on-box check
  pending).

`0.9.106-alpha.1` was superseded before signing (see
[the 0.9.106 record](0.9.106.md)), so its unpublished changelog entry moves
forward as `0.9.107-alpha.1`, with the light-mode change added.
