# Videorc 0.9.126 release

Status (2026-10-01): macOS `0.9.126-beta.1` and Windows `0.9.126-alpha.1`
are **published and verified**. Linux `0.9.126-alpha.1` is a **private
candidate with an owner waiver**; its public manifest has not been uploaded.
