# Videorc 0.35.0 release

## Scope and source

0.35.0 is a **MINOR** release from 0.34.0 (record #1576). It ships the fixes
from the second live talk-show test (plan 254: #1577, #1578, #1580, #1581,
#1582, #1584; web #172 and #173 deployed separately) and the first desktop
slices of latency measuring (plan 253: #1572, #1573), plus test-only fixes
(#1583, #1585, #1586). All are the owner's PRs, merged before this release.
Open PRs from other authors (#1561, #1570, #1579) and the scene HUD (#1416)
stayed out.

- Version/changelog PR: #1587, squash `547d28adb2ed0baba696da72fd94e2166073974c`. PR checks: 17 pass, 2 skipping.
- macOS source commit: `547d28adb2ed0baba696da72fd94e2166073974c`.
- Platform order: **macOS only**. Windows and Linux Alpha are **held, pending
  an owner decision** on waiving the physical-PC acceptance. No Windows or
  Linux changelog entry exists for 0.35.0 and no candidate workflow was
  dispatched.
- No unrelated PRs merged during this release.
- Release started **2026-11-20 08:36 CET** (version PR opened); macOS live at
  **09:03 CET**.

## Gate notes

Final tests ran on main `d4639c669` plus the script-only fix `f09fb8aa8`
(#1586) before the version bump; the release changed only the version and the
changelog.

- CI, Windows CI and Linux CI green on `d4639c669`.
- Recording-studio gate: 40/44. The four reds were diagnosed as not code
  regressions:
  - Separate-source runtime 4K30: red by design since 2026-10-31 (three 4K30
    sources overload and shed).
  - Freeform editor last step: known, same symptom as in the 0.34.0 gates.
  - Live-background Silk p95: host GPU noise, A/B'd against the base with the
    same spread.
  - Smart scenes: a check bug, fixed in #1586, then passed twice including
    camera-return and hide.
- Passed: talk-show, managed cloud talk-show, parity privacy, handoff and
  graphics parity, record-latency smokes, and the web guest-call and
  stage-LiveKit runs.

Packaged-app checks on the built bundle (isolated user data, not the
installed app):

- `smoke:packaged:bundled`: PASS (bundled FFmpeg, backend ready, poster).
- `smoke:packaged:native-preview`: **FAIL, pre-existing**. The packaged
  backend's preview backstop (#966, 2026-10-31) refuses the smoke's
  test-pattern frames, so the surface stays on the Electron proof surface and
  never reports CAMetalLayer. The same harness fails identically against the
  live 0.34.0 build. This is a harness gap, not a 0.35.0 regression; the
  smoke needs a non-test-pattern source to prove the native surface on a
  packaged build.
