# Videorc 0.32.1 release

## Scope and source

0.32.1 is a **PATCH** release from 0.32.0 (record #1537; no feat commit in
the range): Windows microphone resilience to late and bursty DirectShow buffers
(#1525), a Windows D3D11 Stop that no longer waits on the NVIDIA encoder drain
(#1530), a D3D11 Record that reuses the Clips media thread (#1407), the Linux
Wayland shortcut copy (#1529), the remote Record/Stop latency note (#1535) and
CI and smoke hardening (#1434, #1261, #1531, #1532). #1525, #1530 and #1407 are
Pete's (petercr) PRs, merged by the owner's other agent before this release.

- Version/changelog PR: #1538, squash `6069f3690a195b31112952686aa8f730bfae946e`. PR checks:   17 pass    2 skipping .
- Frozen artifact source for all three platforms: `6069f3690a195b31112952686aa8f730bfae946e`.
- Windows and Linux exact-candidate owner waivers: #1539, squash `56e2649806163cb3ab7b8710ccea363c82c722ff`.
  The Windows waiver names `0.32.0-alpha.1` as its predecessor.
- Platform order: **macOS first**, then Linux and Windows. Main held still from the version merge until the waivers merge.
- No unrelated PRs merged during this release.
- Release started **2026-11-19 12:11 CET**; all three platforms live at
  **13:32 CET**.
