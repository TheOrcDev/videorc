# Videorc 0.30.0 release

## Scope and source

0.30.0 is a **MINOR** from 0.29.0 (which shipped macOS-only, record #1415).
New since 0.29.0: bulk takeover import by drag and drop or multi-select
(#1411, from franky47's #704), plus #1413 (unannounced) and the release
pipeline fixes in #1414. Windows and Linux never received 0.29.0, so their
0.30.0 also carries 0.29.0's content: videorc.com/live, "Save my streams on
videorc.com" (plan 241) and faster CI (plan 242, #1406). #1408 ships
unannounced.

- PR checks: **skipped** at the owner's OK (2026-11-16 12:11 CET, "skip checks this is small"). #1414, #1415, version PR #1417 and the Windows sequence fix #1420 were admin-merged without waiting for checks; waivers #1418 merged after its checks passed.
