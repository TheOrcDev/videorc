# Videorc 0.25.1 release

## Scope and source

0.25.1 is a **PATCH** from 0.25.0: Videorc Camera accepts a CMIO producer
identity reported as the literal `unknown`, so Google Meet no longer says
"Videorc isn't running" while Videorc runs with its camera on (#1337, macOS
only). Windows and Linux move to 0.25.1 with no changes.

- No fix PR was needed: main `91c06e86` passed CI JS, Linux gates (with Linux
  clippy) and Windows clippy before the version PR. The long Windows
  stability gates were not waited for (same bar as 0.22.1 to 0.25.0).
- Version/changelog PR: #1338, squash
  `f396ef7d72cb075bbb8121947e036aaf11915a50`.
- Frozen artifact source for all platforms:
  `f396ef7d72cb075bbb8121947e036aaf11915a50`.
- Windows and Linux exact-candidate owner waivers: #1339, squash
  `8fd8d1eae855e1404c1ba853567d03f6351a2e33`.
- No unrelated PRs merged during this release.
- Release started **2026-11-13 13:05 CET**; all three platforms live at
  **14:16 CET** (about 1 h 11 min).
