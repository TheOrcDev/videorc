# Videorc 0.9.94 Beta 1 (macOS)

Dual-orientation simulcast ships: one Go Live streams the horizontal scene to
YouTube, Twitch and X while the saved vertical scene streams to YouTube
Vertical, TikTok and Instagram as its own 9:16 composition. Six destinations
are two encodes. Executes the vault plan "2026-07-14 - Videorc Vertical
Multistream YouTube TikTok Instagram Plan" as rebased on 2026-09-17.

## Scope

- #121: engine (simulcast leg in `StartSessionParams`, aux output composes its
  own vertical scene, bridge routes each target by explicit
  `outputOrientation`), destination lineup (YouTube Vertical, TikTok,
  Instagram, id-keyed cards, manual-key guidance, no-chat state), Go Live
  bandwidth advisory + Instagram step, schematic vertical monitor. Rebased on
  0.9.93: one shared destination cap (5) counts both legs (per-orientation
  Premium cap dropped), vertical targets leave main's provider stream plan and
  take the simulcast profile, a simulcast session never gets a separate
  horizontal encoded role, Windows D3D11 names `dual-orientation-simulcast`
  unsupported (named fallback), one `streamPlatformSchema` in the RPC
  contract, vertical Studio mode needs no simulcast leg.
- #352: version bump to 0.9.94 + changelog entry.
