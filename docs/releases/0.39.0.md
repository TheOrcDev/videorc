Status: draft for the owner's review. Nothing has been released by this work.

## Proposed notes

- macOS `0.39.0-beta.1`: cleaner green-screen hair edges (#2450), Health clears
  an old Preview slowdown after closing it (#2433), and smoother system audio
  when capture timestamps briefly jump (#2430).
- Windows `0.39.0-alpha.1`: Health clears an old Preview slowdown (#2433).
  The macOS audio fix does not apply to Windows, and the Windows green-screen
  path did not receive the hair-edge correction in #2450.
- The dates are draft dates. Confirm them when preparing the release.

The public entries contain only user-facing changes. The generated
[changelog.json review snapshot](drafts/0.39.0/changelog.json) includes these two
entries only. It is not the production changelog or an upload artifact. The
normal changelog builder produces the complete history from `changelog/`.
