# Videorc 0.39.0 release draft

Status: draft for the owner's review. Nothing has been released by this work.
The owner prepares and runs the release. The desktop package still declares
0.38.0; this PR adds notes only, without starting version preparation, building
release artifacts, signing, uploading, promoting or changing workflows.

## Proposed notes

- macOS `0.39.0-beta.1`: cleaner green-screen hair edges (#2450), Health clears
  an old Preview slowdown after closing it (#2433), and smoother system audio
  when capture timestamps briefly jump (#2430).
- Windows `0.39.0-alpha.1`: Health clears an old Preview slowdown (#2433), and
  the shared audio clock avoids brief gaps when system-audio capture timestamps
  jump (#2430). That audio issue was reported on macOS, but the correction is
  shared across platforms. The Windows green-screen path did not receive the
  hair-edge correction in #2450.
- The dates are draft dates. Confirm them when preparing the release.
- Both platform drafts also include the removal of the Retro LCD look and its
  Settings → General switch. Existing settings with Retro LCD enabled load
  normally with the standard look. **Landed after the readiness pin:** #2442,
  commit `000c5a303ae70203e5ec06e6d213623202118fbb`, is not part of
  `ed29c48daf18676b3143ec2b996dc10d0ca1324c` and is not certified by that pass.
  The owner must choose a release SHA containing this change to retain its note.

The public entries contain only user-facing changes. The generated
[changelog.json review snapshot](drafts/0.39.0/changelog.json) includes these two
entries only. It is not the production changelog or an upload artifact. The
normal changelog builder produces the complete history from `changelog/`.
