# Videorc 0.13.0 release

Status (2026-10-26): macOS `0.13.0-beta.1`, Windows `0.13.0-alpha.1` and
Linux `0.13.0-alpha.1` are **published** (Windows and Linux owner-waived).
0.13.0 is a minor bump: better recordings, from the mic to the exported file
(#845). The other changes since 0.12.0 are fixes and performance work (#832,
#836 to #842, #844). #846, #847 and #848 were still open and are not in this
release.

The owner asked for the whole release end to end, without pausing for
approvals or merges. The owner waived physical acceptance per OrcDev.
