# Videorc 0.9.106 release

Status: preparing macOS arm64 `0.9.106-beta.1` and Windows 11 x64
`0.9.106-alpha.1` from protected main plus this prep update. Neither artifact
has been signed or published.

## Scope and source

Since macOS 0.9.105 (`c2038a0b7187e659bad075afe28f9648deb8dd95`), protected
main gained:

- **#408, microphone dropouts since 0.9.103 (plan 056).** Every microphone
  take since #389 could drop packets that the session-audio bus rendered as
  exact-zero holes, worst with 128-frame CoreAudio callbacks (Shure MV7+).
  The bus now buffers one second in time instead of 32 packets, keeps
  ingesting the microphone while its FIFO write is blocked, and FFmpeg's
  audio input queue is 1024 packets again. Every loss is logged by reason
  when the bus closes, and the recording analyzer gained a digital-zero gate.

`0.9.105-alpha.1` was superseded before signing (see
[the 0.9.105 record](0.9.105.md)), so its unpublished changelog entry moves
forward as `0.9.106-alpha.1`, with the dropout fix added.

Mac source commit: pending merge of this prep update. Windows candidate source
commit: recorded after macOS publication.
