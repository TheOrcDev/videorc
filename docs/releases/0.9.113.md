# Videorc 0.9.113 release

Status: macOS `0.9.113-beta.1` is **published and verified** (2026-09-25
~23:01Z). It turns Kick OAuth on: the release env now carries
`VIDEORC_BUNDLED_KICK_CLIENT_ID` / `VIDEORC_BUNDLED_KICK_CLIENT_SECRET`.

[36199423442](https://github.com/TheOrcDev/videorc/actions/runs/36199423442)
was dispatched from `433a52b8` and cancelled once #452/#453 (0.9.114) moved
`main` past it; its entry moved forward to `0.9.114-alpha.1`. Superseded by
0.9.114 the same night. No Windows Alpha is public yet.
