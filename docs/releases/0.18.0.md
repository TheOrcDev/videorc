# Videorc 0.18.0 release

Status (2026-11-02): macOS `0.18.0-beta.1`, Windows `0.18.0-alpha.1` and
Linux `0.18.0-alpha.1` are all **published**. Windows and Linux are
owner-waived. 0.18.0 is a minor: plan 213 adds Camera look (#1017),
Continuity Camera (#1015), screen crop / Fill for landscape (#1029), the
Preview inside the main window (#1018, #1032), the Chat row in the Studio
inspector (#1010) and displays that survive hot-plug (#1019), plus fixes
#990–#998, #1000–#1003, #1006, #1007, #1011–#1014, #1016, #1020–#1026,
#1028, #1030 and #1031.

The owner asked for the whole release end to end, without pausing for
approvals. Physical acceptance waived per OrcDev.

## Source

- Bump and changelog: #1033, squash `471dcf34f3488870f0a0c2dba1cb0c3f387ceb27`.
  All three platforms build from this commit.
- Windows and Linux owner waivers: #1034, squash
  `b121c8c98b1189c495b87341e3a678119a8a9e50`, merged only after the Windows
  signing job had finished. Nothing else merged to main during the release.

## Main CI on the pre-release head (`c9e878f5`)

- `Rust (test + clippy + fmt)` failed (known-bad hosted macOS check).
- `Linux gates` failed: first a runner shutdown, then on rerun one test,
  `recording::tests::camera_look_ffmpeg_eq_agrees_with_float_law` (#1017),
  which spawns FFmpeg and panics where CI has no FFmpeg on PATH. Test harness
  gap, not a build break. On `471dcf34` push CI passed (version-release scope).
- `Windows startup incident diagnostics`: known-bad, ignored per runbook.
