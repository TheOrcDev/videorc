# Videorc 0.17.0 release

Status (2026-10-30): macOS `0.17.0-beta.1`, Windows `0.17.0-alpha.1` and
Linux `0.17.0-alpha.1` are all **published**. Windows and Linux are
owner-waived. 0.17.0 is a minor bump because of #935 (Scenes for your apps)
and Hide screen. Windows skipped 0.16.0, so its 0.17.0 alpha also carries
the 0.16.0 changes.

The owner asked for the whole release end to end, without pausing for
approvals or merges. The owner waived physical acceptance per OrcDev.

## Source

- Bump and changelog: #940, squash `e23011f54be719004c80f36be402120b69274d58`
  (merged 12:54:48Z). All three platforms build from this commit.
- Windows and Linux owner waivers: #941, squash
  `5dc0222840c4b25e25c5244d8b2581ae10504e08` (merged 13:30:16Z). It was
  merged only after the Windows signing job had finished.
- Nothing else merged to main while the Windows candidate was building, so
  the protected-main recheck after approval passed. That recheck is what
  stopped Windows 0.16.0.

## Known gaps

- `/releases/<version>-alpha.1` pages answer 404. This is also true for
  0.15.1 and 0.16.0, so it is not new.
- `docs/acceptance/linux-alpha/0.16.0-alpha.1.json` (#921) is malformed JSON.
  A zsh `$S:s` modifier ate part of the `candidateIdentity` line when it was
  generated. 0.17.0 records were generated without that bug.
