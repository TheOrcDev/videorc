# Videorc 0.16.0 release

Status (2026-10-30): macOS `0.16.0-beta.1` and Linux `0.16.0-alpha.1` are
**published** (Linux owner-waived). Windows `0.16.0-alpha.1` is **not
published**: its signing job failed the protected-main recheck (see below).
0.16.0 is a minor bump: Liquid Chrome highlights in Stream Manager (#910) and
Buddy talking only in its bubble (#914), plus #905, #907, #908, #909, #911,
#912, #913, #916, #917 and #918. #915 was left out: it fails the renderer
initial asset budget.

The owner asked for the whole release end to end, without pausing for
approvals or merges. The owner waived physical acceptance per OrcDev.

## Source

- Bump and changelog: #919, squash `f44c841305f2250f2ace17264d2182b1c26b1143`
  (merged 14:08:06Z on 2026-10-29). All three platforms build from this
  commit. #919 also silences one `react-hooks/exhaustive-deps` lint warning
  that was already on main.
- On `f44c8413` the JS job fails only the renderer initial asset budget
  (eager JS gzip 410,023 bytes against a 410,000 limit). That overrun is
  already on main and was treated as known.
- Linux owner waiver: #921, squash `c8ec8ee53083943c22ab33290123286140a2640a`
  (merged 09:43:43Z on 2026-10-30).
