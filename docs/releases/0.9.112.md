## Scope and source

Since macOS 0.9.111 (`7646c43c1e2107bbd8f7b88bd36745049b6db1c5`):

- **#445, shortcuts by pressing keys (plan 062).** Settings → Global
  shortcuts records a combination from key presses; main owns key capture
  while a field is armed; per-platform accelerator spelling.
- **#446, Linux Alpha upload path** (withheld from macOS publication).
- **#447, Kick (plan 063).** Kick as a horizontal destination with Manual
  RTMP; OAuth connect, API stream key, title/category, chat through the
  videorc-web relay (web #44), viewers and follow deltas, all dark until
  `VIDEORC_BUNDLED_KICK_CLIENT_ID` / `_SECRET` ship in a release env.
  Includes the fix for TikTok/Instagram accounts reloading as Custom and
  the readiness fix where PKCE counted as a secret.
- **#448**, version bump, changelog entries, CI ceiling.
