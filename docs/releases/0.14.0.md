# Videorc 0.14.0 release

Status (2026-10-27): macOS `0.14.0-beta.1`, Windows `0.14.0-alpha.1` and
Linux `0.14.0-alpha.1` are **published** (Windows and Linux owner-waived).
0.14.0 is a minor bump: Discord announcements in every server, one webhook
per server (#860), and Microphone and System audio balance in the Studio
(#864). #846, #847, #843 and #862 were not in this release.

The owner asked for the whole release end to end, without pausing for
approvals or merges. The owner waived physical acceptance per OrcDev.
