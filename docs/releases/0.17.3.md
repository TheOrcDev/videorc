# Videorc 0.17.3 release

Status (2026-11-01): macOS `0.17.3-beta.1`, Windows `0.17.3-alpha.1` and
Linux `0.17.3-alpha.1` are all **published**. Windows and Linux are
owner-waived. 0.17.3 is a patch: since 0.17.2 main has only #965 (the Preview
shows the program when the Clips ring starts first), #966 (the Preview never
shows test noise), #952 (smokes stop the whole cargo build on timeout) and #968
(CI). No new integration, destination, platform or Streaming Buddy capability.

The owner asked for the whole release end to end, without pausing for
approvals. Physical acceptance waived per OrcDev.

## Source

- Bump and changelog: #969, squash `6fd9846ca215fc66fca6e997f46f7bad9629cc33`.
  All three platforms build from this commit.
- Windows and Linux owner waivers: #970, squash
