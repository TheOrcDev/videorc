Status (2026-10-22): macOS `0.9.144-beta.1`, Windows `0.9.144-alpha.1` and
Linux `0.9.144-alpha.1` are **published** (Windows and Linux owner-waived).

- Bump and changelog: #731, squash `609a10cd070c9f0a8c6b93cb2f2c5b5ce4a839b9`.
  All three platforms build from this commit. `main` CI on it: Rust (test,

  recent Betas.
- Alpha changelog entries are not public, and no Alpha Discord post was
  sent, as for every Alpha since `0.9.91-alpha.1`.
- The signed-in download pages were not checked by eye.
- #730 merged on the owner's word while its own Rust CI job was still running
  (its Test step passed; only the memory sentinel build hit the 75 minute job
  limit) and with its Windows source gates red on `session_audio` timing tests
  in the 25-pass stress step; the same gates passed on #729's rerun and on
  `main` at the source commit.

  smoke are sensitive to runner load and failed once each during this cut.
