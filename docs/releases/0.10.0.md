# Videorc 0.10.0 release

Status (2026-10-25): macOS `0.10.0-beta.1`, Windows `0.10.0-alpha.1` and
Linux `0.10.0-alpha.1` are **published** (Windows and Linux owner-waived).
0.10.0 is a minor bump: Streaming Buddy now greets and talks on its own, and
live backgrounds move on the live stream.

The owner asked for the whole release end to end, without pausing for
approvals or merges.
