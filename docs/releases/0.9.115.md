## Scope and source

Since macOS 0.9.114 (`a454509005557671a69fa7f248995a9caa64c08c`):

- **#458, Kick streams go live.** Kick's channel read returns `stream.url` as
  the bare ingest host, so 0.9.113 and 0.9.114 pushed to
  `rtmps://<host>/<key>` and Kick refused every stream ("Input/output
  error"). `kick_ingest_server_url` builds `rtmps://<host>:443/app`. Stream
  keys and URL credentials are masked in `emit_log` and `emit_health_event`
  (backend log, in-app log, persisted health events, support bundles).
- **#455,** the on-brand "You're now connected to Videorc" OAuth page.
- **#457,** Windows only: the microphone survives a capture-worker start
  failure, and the Quick Sync probe uses a video-capable, multithread-protected
  device with a system-memory fallback and a remembered rejection (plan 065).
- #437 (Linux portal proof pixels), #454, #459: Linux-only work, records and
  the bump.
