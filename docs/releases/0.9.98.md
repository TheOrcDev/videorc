# Videorc 0.9.98 Beta 1 (macOS) and 0.9.98 Alpha 1 candidate (Windows)

Phone remote, and the first release published to two storage origins with
Hetzner as the primary.

## Scope

- #355: Phone remote. A second axum router on `0.0.0.0:7420`, bound only while
  the feature is enabled (off by default), serving a web remote to phones on
  the LAN: live chat monitor, tap-to-highlight, scenes, takeovers, mic mute,
  start/stop. Per-device keys from a single-use five-minute QR pairing ticket,
  HMAC challenge-response and MAC'd, sequence-numbered client frames over
  plain HTTP/WS. Remote sockets no longer receive `backend.ready`.
- #369: two release storage origins in the uploader, `release:sync:origins`,
  and the updater's one-shot mirror retry (`updater-mirror.ts`). This is the
  first build that carries the retry.
- #371: an uploader only introduces its own platform's changelog entries.
- #368: version bump and the macOS changelog entry. #372: the Windows Alpha
  entry, and removal of the abandoned `0.9.97-alpha.1` entry.
- Web: videorc-web #25 (mirror routes, `?mirror=1`, primary switch), live since
  2026-09-21 with `VIDEORC_DOWNLOAD_STORAGE_PRIMARY=hetzner`.

## Owner decisions taken by shipping

Phone remote's open plan decisions were settled by the owner's instruction to
ship 0.9.98: O1 plaintext HTTP/WS with HMAC on the LAN (iOS Safari refuses
`wss` to a self-signed certificate; the residual is an active attacker on the
same Wi-Fi tampering with the served page), O2 available on the free tier, O3
the name "Phone remote" and port 7420.
