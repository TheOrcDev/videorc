# Videorc 0.17.1 release

Status (2026-10-30): macOS `0.17.1-beta.1`, Windows `0.17.1-alpha.1` and
Linux `0.17.1-alpha.1` are all **published**. Windows and Linux are
owner-waived. 0.17.1 is a patch: the only change since 0.17.0 is #943 (every
window is the plain solid; the frosted chrome ground is gone).

The owner asked for the whole release end to end, without pausing for
approvals or merges. The owner waived physical acceptance per OrcDev.

## Source

- Bump and changelog: #944, squash `1e10954f31cfe3de56c7957b242f4ce9cd347a36`.
  All three platforms build from this commit.
- Windows and Linux owner waivers: #945, squash
  `131ef70b5324a2db670a7f5fb040f1cbc066ca5c`, merged only after the Windows
  signing job had finished. Nothing else merged to main during the Windows
  candidate run.
