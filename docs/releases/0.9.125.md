### Build-machine note

The shared `stable` Rust toolchain on the build Mac had lost
`lib/rustlib/aarch64-apple-darwin/bin` (no `rust-objcopy`; directory modified
2026-10-01 10:28), so the release profile could not strip. The build used a
side-by-side `1.98.0` toolchain (the same compiler version) with the
`x86_64-apple-darwin` target, selected with `RUSTUP_TOOLCHAIN=1.98.0`. The
`stable` toolchain is still broken for release builds.
