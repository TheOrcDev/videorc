# Videorc 0.9.97 Beta 1 (macOS) and 0.9.97 Alpha 1 candidate (Windows)

Everything built on 2026-09-20 after 0.9.96: the Chat window rework, the
performance check, and the Windows low-end iGPU recording fix.

## Scope

- #363: Comments → Chat rename in every user-visible string, glass material on
  the Chat and Captions windows (macOS), header aligned with the traffic
  lights, four-corner `Highlight position` picker (`CommentHighlightAnchor`,
  one layout oracle across CPU, Metal and D3D11), username beside the avatar.
- #365: performance check. A hidden ladder of real sessions (4K30 → 720p30) on
  the hard-content test pattern, a recommended output in Recording → Output,
  Verified / Too heavy preset labels, 1080p30 as the default until the machine
  is measured, auto-apply only for an output nobody chose.
- #364: drain-aware stop ladder and `recording-stop-forced`, Media Foundation
  probe resolution step-down, interim OpenH264 cap, persisted FFmpeg stderr
  tail, Windows copy.
- Companion web change videorc-web #24 (merged `2e955c51`, deployed by the
  merge): co-host question summaries and replies pinned to English. Nothing on
  the wire changed.
- #366: version bump to 0.9.97 and the macOS changelog entry. #367: the Windows
  Alpha changelog entry, merged only after the macOS upload was verified.

## Gates

- Hosted CI did **not** test #363 or #365 on macOS: the JS and Rust jobs fail in
  the advisory dependency audits, which run first, so format, lint, typecheck,
  the desktop tests, clippy and the Rust tests were all skipped (js-yaml
  GHSA-2883-xcg3-v3hh via electron-updater; RUSTSEC-2026-0285). Windows gates
  and Linux gates were green on both. The Windows installer job was green on
  #365 and red on #363 in the packaged-recording check
  (`Timed out waiting for sessions.poster`), the known hosted-runner flake.
- Because of that, the gates were run locally on the exact merged tree before
  merging. Both branches were trial-merged onto `main`; the resulting tree
  `cba2332b` is byte-identical to `main` after the two squash merges. On it:
  `pnpm typecheck`, `pnpm lint`, `pnpm format:check`, `pnpm test:scripts`,
  `pnpm changelog:check`, desktop vitest (1710 passed, 1 skipped),
  `cargo fmt --check --all`, `cargo clippy -p videorc-backend -- -D warnings`,
  full `cargo test -p videorc-backend` (2196 passed, 0 failed, 9 ignored), all
  pass. `cargo build --release` passed as part of packaging.
- Feature smokes were run on the feature branches, not repeated here: see
  `docs/acceptance/2026-09-20-chat-window-glass-and-highlight-corners.md` and
  `docs/acceptance/performance-check-calibration.md`.
- Not run for this beta: real-device screen/camera/microphone gates, strict
  provider readiness, the 75-minute capture-decay sentinels, the signed-in
  download-page check, the clean-machine acceptance template. Owner by-eye
  passes for #363 (traffic-light alignment, glass on a real wallpaper, the four
  corners live) and #365 (preview noise during the check) were still pending
  when the owner asked for the release.
