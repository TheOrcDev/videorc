# Videorc 0.24.0 release

## Scope and source

0.24.0 is a **MINOR** from 0.23.0: HTML banners, animated overlays with a
transparent background, first slice on macOS (#1323, plan 232); a check before
going live Unlisted or Private on YouTube (#1316); and a slow scene switch that
keeps the clicked name and says what it waits for (#1312, #1275). Fixes: the
YouTube go-live chat id lookup is retried (#1317), mid-stream captions are
delivered and AI outages explained (#1315), Buddy greets named viewers from
voice (#1318), and an animated background comes back after it is stepped down
(#1322). Internal only: #1321 (clippy 1.100 fix) and #1311 (Windows smoke).

- No fix PR was needed: main `e4750832` passed CI Rust and JS, Linux, and
