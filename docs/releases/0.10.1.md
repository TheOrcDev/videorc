# Videorc 0.10.1 release

Status (2026-10-25): macOS `0.10.1-beta.1`, Windows `0.10.1-alpha.1` and
Linux `0.10.1-alpha.1` are **published** (Windows and Linux owner-waived).
0.10.1 is a patch bump: LCD-style level meters, Copy on Linux error messages,
and a fix for cancelling a Buddy pet sheet.

The owner asked for the whole release end to end, without pausing for
approvals or merges. The owner waived physical acceptance per OrcDev.
