# Videorc 0.27.0 release

## Scope and source

0.27.0 is a **MINOR** from 0.26.0: the avatar and Sidekick become two products
(#1372, plan 239), a calm Preview start (#1369, plan 238), green screen on the
Studio's Camera row, in ⌘K and first in the camera's inspector (#1368), a
session start never saves a stream key in plain text and old copies are purged
(#1364), and Windows D3D11 encoder fixes (#1362, #1373). Also on main: test
fixes (#1361, #1365) and two plan 234 fixes (#1367, #1375) that stay behind
their server-side switches and are left out of the changelog and announcement.

- #1373 had been squash-merged into #1362's branch 9 seconds after #1362
  merged, so it never reached main. It was re-landed unchanged as #1376
  (cherry-pick of `418e1947`), squash `0f3817a88c12b1c7c667d71b46095ea4ea71ac3c`, after its CI JS, Linux gates
  (with Linux clippy) and Windows clippy passed.
- Version/changelog PR: #1377, squash `f79a5bf54e3e3939178108fc1f02f2bcf2127c5d`.
- Frozen artifact source for all platforms: `f79a5bf54e3e3939178108fc1f02f2bcf2127c5d`.
- Windows and Linux exact-candidate owner waivers: #1378, squash `7a039b9ed27e44fa38f589158715aef235f84715`.
- Platform order: **macOS first** (owner rule, so the owner can test it), then
  Linux and Windows.
- No unrelated PRs merged during this release.
- Release started **2026-11-15 11:10 CET**; all three platforms live at
  **12:22 CET**.
