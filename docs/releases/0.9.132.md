# Videorc 0.9.132 release (with 0.9.130 and 0.9.131 macOS)

Status (2026-10-05): macOS `0.9.132-beta.1`, Windows `0.9.132-alpha.1` and
Linux `0.9.132-alpha.1` are **published** (Windows and Linux owner-waived).

published on the way; their Windows and Linux Alphas were abandoned unpublished
because `main` advanced before promotion.

## macOS (published)

All three were built locally in `../videorc-wt-rel0130` with
`RUSTUP_TOOLCHAIN=1.98.0`; signing, notarization, stapling and
`release:validate:macos` pass, including the bundled YouTube, X and Kick
credential checks. Uploaded to r2, Hetzner and Neon (primary). Each upload
withheld its own Alpha entry.
