# Official Golem characters

Golmar the Orc, Nib the Goblin, Captain Barnacle the Pirate and Bolt the
Robot (plan 170 D10, D11), four poses each, exported by `pnpm
golem:official` from the masters in `assets/brand/golem/official/` (see
`assets/brand/golem/README.md`). The Golem's official poses are `../default/`.
The backend bundles the same files for the stream overlay. Keep any pose
under 200 KB; `lib/golem-official-assets.test.ts` checks every file.
