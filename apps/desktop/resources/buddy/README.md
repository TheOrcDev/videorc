# Bundled Golem pet packs

Read-only pet packs shipped with the app (plan 168 D3): each `<name>/` folder
here is the pack `bundled:<name>` (`manifest.json`, its sheets, `golem.json`),
packaged as `golem-assets/bundled` and passed to the backend as the second
`VIDEORC_MANAGED_GOLEM_ROOTS` entry. Our default Golem (`golem/`) arrives in
plan 168 Phase G; only our own art goes here, never a third-party pack.
